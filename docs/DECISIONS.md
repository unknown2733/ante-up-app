## 후속 결정으로 바뀐 부분

1. **무가중 28일 산식:** 직전 28일 합계 D 고정·주중 실제 교체 A안을 먼저 선택했지만 이후 시간 가중·EWMA 방향으로 바뀌었다. 이 산식은 이력이며 최종 구현식은 재설계한다. 실제 관측·주중 갱신·가격 이월·권리 연속성은 유지한다.
2. **졸업 배율의 주간 적용:** 졸업 시 가격 연결과 사용자별 임의 재설정 금지는 유지한다. 모든 주간에 동일한 성장률 배율 c를 쓰던 부분은 가격 이월 결정으로 변경됐다. 예전 고정 `5c` 가격 상단을 새 연속 가격의 지급 보장으로 사용하지 않는다.
3. **WMA/EWMA 미선택:** 시간 가중 방향 선택 뒤 EWMA를 선택했다. 방법은 해소됐지만 수치·최종 가격식은 미정이다.
4. **7장 피치:** 현재는 8장 구조를 채택했다. 기존 7장 목업은 시각 참고·제작 이력이다.
5. **협찬권·경제 연결의 과거 후보:** 미래 협찬권 및 현재 검토에서 제외된 자산 설정/환매·사용권/사업 수익권·참가금 배분을 지금의 제품 전제로 사용하지 않는다.
