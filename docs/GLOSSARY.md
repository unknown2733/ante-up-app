# 프로젝트 용어집

팀원 설명을 위한 문맥상의 정의다. 최종 상품 계약이나 외부 프로토콜 전체의 정의를 대신하지 않는다. 2026-10-11 기준이며 채택 범위는 [DECISIONS](DECISIONS.md), 실제 미정 명세는 [PRD](PRD.md)에서 확인한다.

블록체인 자체가 처음이라면 [기초 설명](BLOCKCHAIN_BASICS.md)을 먼저 읽는다. 본딩커브는 초기 가격 규칙, 풀은 교환할 자산, AMM은 자동 교환 방식, LP는 자산 공급자, 보호형 거래는 특정 위험을 다루는 계약으로 연결해 설명했다. 일반적인 원리와 Ante Up의 채택/TBD를 구분한다.

| 용어 | 여기서 뜻하는 것 | 현재 경계 |
|---|---|---|
| 블록체인 / Solana | 거래·기록을 함께 유지하는 네트워크 / 이 프로젝트에서 선택한 네트워크 | 외부 데이터의 정확성이나 제품 안전성이 자동 증명되는 것은 아님 |
| 지갑 | 자산을 조회하고 거래 요청을 서명·승인하는 도구 | 프로젝트의 실제 지갑 연동은 미정 |
| 토큰 | 네트워크에서 소유·이동을 기록하는 디지털 단위 | 특정 지분·수익·환매권을 준다는 뜻은 아님. 권리는 상품별 계약에 따름 |
| 스마트컨트랙트 / 프로그램 | 네트워크에서 거래 규칙을 실행하는 코드 | 실행 요청·자산·권한·규칙을 실제로 설계해야 함 |
| 프로토콜 | 이 프로젝트에서 거래·기록·권리 처리의 규칙과 구현을 묶어 부르는 말 | 구체 온오프체인 책임·코드는 미정 |
| 유동성 풀 | 거래에 사용할 자산을 모아 둔 구조 | 자산 구성이 달라질 수 있음. Ante Up의 실제 자산/담보 배정 미정 |
| AMM | Automated Market Maker, 규칙으로 견적을 내고 풀의 자산을 교환하는 방식 | 특정 AMM·공식 미채택. 외부 관심 추종이 자동 성립하지 않음 |
| Ante Up | 인터넷 관심의 조기 판단 기록과 선택적 금전 참여를 연결하는 제품명 | 도메인은 ante-up.fun; 라이브 제품 상태는 별도 |
| Call | 어떤 대상에 대한 판단·선택을 남기는 행동 | 전화 통화 뜻이 아님. 칩이 정확히 표현하는 의미·입력 필드는 미정 |
| Keyword / 키워드 | 참여와 관측을 연결하는 대상의 단위 | 첫 MVP는 영어 키워드; 계정/개별 영상 직접 지원은 이후 범위 |
| Attention / 관심 | 외부에서 관측할 활동과 그 변화 | 호감·지지·품질·평판과 별개. 공급자·단위는 미정 |
| Chip / 칩 | 기본 사용자에게 참여를 표현하는 단위/경험 | 무료·금전 경로가 있음. 금전 칩을 특정 토큰·현물·보호 계약으로 확정하지 않음 |
| Caller | 판단을 남기고 관심을 관찰·종료·공유하는 경로의 사용자 | 다른 역할과 중복 가능 |
| Trader | 관심 변화에 실제 금전 포지션을 여는 참여 경로 | 권리·비용·가격·지급식 설계 필요 |
| LP | Liquidity Provider, 거래를 뒷받침하는 자본/유동성 공급자 | 무위험 예금이 아님. 손실·평가·출금·배분 미정 |
| 기본 / Pro | 소비자 칩·기록 경험과 레버리지·LP 경로의 구분 | 기본에도 금전 참여가 있으며 최종 브랜딩/권리 전환은 미정 |
| Long / 롱 | 연결된 거래가격이 오르는 방향의 금융 노출 | 대상의 품질·호감에 대한 판정이 아님. 지급식은 미정 |
| Short / 숏 | 연결된 거래가격이 내리는 방향의 금융 노출 | 롱 식의 부호만 바꿔 지급을 확정하지 않음 |
| Leverage / 레버리지 | 투입 자본보다 큰 방향 노출을 다루는 거래 조건 | 최대 진입5배 초기 기준; 보호·비용·담보·유지 조건은 미정 |
| 청산 | 포지션의 유지 조건을 충족하지 못해 강제로 정리되는 것 | 보호형 상품마다 가격·비용·종료 조건이 다름. Ante Up의 정확한 규칙 미정 |
| 프리미엄 | 보호/권리 이용의 대가로 논의하는 비용 | 실제 부과 기준·요율·납부/환급 규칙 미정 |
| 보호형 포지션 | 풀·LP의 자산/권리와 비용을 연결하는 우선 거래 설계 방향 | 무엇을 보호하고 무엇을 제외하는지 미정. 무손실·무비용·무제한 체결을 뜻하지 않음 |
| Vault / 볼트 | 자본과 지급 의무·예치 지분을 관리할 키워드별 구조 | 졸업 자본 잠금·외부 예치 방향. 정확한 계정/자산·회계·권한은 미정 |
| Bonding curve / 본딩커브 | 초기 자본·가격 형성 단계에서 검토하는 판매/가격 규칙 | 실제 곡선·초기 가격·물량·체결 방식은 미정 |
| Graduation / 졸업 | 초기 자본 형성 단계에서 지수 연동 거래를 위한 단계로 넘어가는 전환 | 자본 잠금·가격/권리 연속성 방향; 조건·전환 순서·실패 처리 미정 |
| EWMA | Exponentially Weighted Moving Average. 최근 관측을 반영하고 오래된 활동의 비중을 지수적으로 줄이는 방식 | 방향만 채택. 반감기·비교 간격·초기값·최종 가격식 미정 |
| 반감기 | 오래된 활동의 가중치가 절반이 되는 시간의 설명 단위 | 구체 수치 미선택. 조회 빈도만으로 정하지 않음 |
| Oracle / 오라클 | 외부 관측을 프로토콜에 전달·적용하는 경로 | 공급·게시·버전·정정·지연·주문 적용 규칙은 미정 |
| 가격 이월 | 다음 주 기준가격이 직전 마감가격을 이어받는 방향 | 주간 기준 변경만으로 기존 권리를 초기화하지 않음. 최종 EWMA 연결식은 미정 |
| SAS | Solana Attestation Service. 당시 선택·출처·결과를 확인하는 증명 설계의 중심으로 선택한 방향 | 실제 발급/스키마·원문 보관·데이터 진실성은 별도 확인 |
| Seeker | 이 프로젝트에서 실기기 모바일 데모를 목표로 삼은 Solana 모바일 기기 | 지원 기능·앱·지갑 연동·조작의 실제 동작은 검증 필요 |
| ICM / Token Supercycle | 인터넷에서 발견한 대상에 판단과 자본으로 참여하는 제품의 상위 방향 | 제휴·생태계 공식 승인 또는 별도 구현 기능을 뜻하지 않음 |
| Devnet | 개발/검증 환경의 Solana 네트워크 구분 | 실제 구현 환경일 때 표시. 실자금 운영 완료와 구분 |
| ADL | Auto-Deleveraging, 자동 위험/노출 축소 계열의 장치로 참고하는 용어 | 구체 발동·배분·보호 규칙은 채택되지 않음 |
| TBD | To Be Determined, 아직 결정되지 않은 항목 | Codex가 임의로 숫자·소스·스택을 넣지 않음 |

SAS·EWMA 등의 풀네임은 용어 이해를 위한 설명이다. 외부 서비스의 현행 API·지원 기능·SDK를 구현할 때는 공식 문서를 별도로 확인해야 한다.
