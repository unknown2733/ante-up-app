# Ante Up — PRD

기준일: 2026-10-11. 프로젝트 ID: `solana-colosseum`.

이 PRD는 기존 채택 범위를 제품 요구사항 형태로 정리한 공유용 초안이다. **최종 구현 명세는 아니며, 미결정 데이터·수치·계약·스택은 TBD로 유지한다.** 아래 번호와 문서 구조는 정리용 식별자이며 사용자 선택을 추가하지 않는다.

제품을 처음 듣는다면 [아이디어 맥락과 가상 사례](CONTEXT.md)를 먼저 읽고, [용어집](GLOSSARY.md)을 함께 사용한다. 이 문서의 ‘요구사항’은 채택한 방향을 정리한 것이며 실제 구현의 완료 상태가 아니다.

본딩커브·LP·AMM·보호형 거래의 배경은 [블록체인·거래 기초](BLOCKCHAIN_BASICS.md)에 짧게 설명했다. 일반적인 원리를 제품의 최종 계약으로 읽지 않는다.

## 1. 목적과 첫 사용자

인터넷 관심의 조기 판단을 기록하고, 같은 대상의 관심 변화에 선택적으로 금전 참여하는 경험을 제공한다. 첫 사용자는 X·밈·트렌드를 먼저 찾는 온체인 참여자다. 최초 판단 시점·후속 관심 변화·실제 금전 결과를 별도로 확인한다.

전체 가치·장기 방향은 [제품 비전](PRODUCT_VISION.md), 채택 범위와 변경 이력은 [확정 결정사항](DECISIONS.md)을 따른다.

**발견/검색 → 대상·관측 기준 확인 → 판단 기록·칩 또는 별도 포지션 → 변화 관찰 → 원하는 순간 종료 → 결과·근거 확인/공유.**

## 4. 관측·성과·가격 표시의 구분

사용자 기록에는 당시 대상·시점·원문·관측 근거와 이후 결과를 연결하는 방향이다. 성장률·비교 구간·관측값·지표/가격 버전·금전 진입/종료 가격·비용이 금전 결과 해석에 필요하다. 정확한 저장 필드와 SAS 스키마는 TBD다.

- 최초 판단 시점과 금전 진입 시점은 별도로 표시한다. 나중의 금전 진입을 과거 무료 기록 시점으로 소급하지 않는다.
- 외부 관심 변화와 무료 기록 성과, 거래 손익을 하나의 점수로 자동 통합하지 않는다.
- 호감·지지·평판과 관심 지표를 구분한다. 논란으로 관심이 커지는 경우에도 의미를 혼동하지 않는다.
- 외부 관심 지표 I, 거래 기준가격 P, 실제 종료 지급액 V를 구분한다.
- 표시용 보간이나 같은 원천 관측의 재조회는 새 실측·체결 가격을 뜻하지 않는다.
- 무관측·결측과 실제 0건은 다르다. 처리 방식은 데이터 명세에서 결정한다.

## 5. 경제 구조와 적용 제한

풀 기반 보호형 구조를 우선하며, 졸업 자본과 외부 예치 자본이 키워드별 볼트의 교환·보호를 뒷받침하는 방향이다. 자본 제공자는 순손익에 참여하고 프로토콜은 명시된 규칙에 따라 보상을 받는다. 자산 사용·출금은 기존 지급 의무를 유지하는 범위여야 한다.

**최대 진입 레버리지 5배·성장률 상한 +400%**는 초기 설계 기준이다. 최신 EWMA 가격식에 대한 적용 대상·구간·실제 최대 지급 책임은 TBD다. 같은 자산을 중복 담보로 세지 않으며, LP 자산 변동·수수료/프리미엄·볼트 순손익·배분 가능 수익을 구분한다.

주간 성과 기준·관측/오라클 게시·체결·장부 클리어링·현금 정산·보호 기간/갱신은 별도다. 모두 7일이거나 주간 경계에서 계약이 종료되는 것으로 정하지 않았다.

이전 무가중 28일 합계와 경과분 교체 산식은 EWMA 채택으로 재설계 대상이다. 최종 가격식·숏의 지급·담보 배정·쏠림·동시 종료·동적 한도·ADL·예외 처리는 구현 전에 별도로 닫아야 한다.

### 초기 참여와 보상에 관한 기존 제약

시장이 처음 생길 때 자본을 넣는 사람은 아직 참여자가 적은 시장의 거래를 가능하게 하는 데 기여한다. 기존 사용자 지시는 **그 기여를 인정하면서, 아주 조금 먼저 들어왔다는 이유만으로 보상이 지나치게 커지는 것은 줄이자**는 것이다.

- 초기 자본 공급의 기여를 인정한다. 구체적인 보상 권리나 배분 비율은 아직 정하지 않았다.
- 외부 트렌드 변화와 무관한 매매 이익도 허용하는 범위다. 모든 선점 수익을 없애는 목표로 해석하지 않는다.
- 본딩 단계부터 외부 관심 지수를 가격에 강제로 연결할 필요는 없다는 제약이다. 졸업 이후 지표 연동 거래의 계약과 구분한다.
- 과도한 선점 보상을 줄이되, 초기 자본이 모일 유인도 검토한다. ‘과도함’의 수치·보상 한도·커브·물량·주문 방식은 TBD다.

예를 들어 두 사람이 비슷한 시점에 같은 규모의 자본을 넣었는데 아주 짧은 순서 차이가 큰 보상 차이를 만든다면 검토할 문제다. 이는 설명용 상황이며 동일 수익 보장이나 특정 경매·배치 체결 방식의 채택이 아니다. 토큰 초기 구매와 외부 LP 예치는 서로 다른 권리이므로 자동으로 같은 보상을 부여하지 않는다.

근거는 정본 `20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md`의 **‘초기 보상에 관한 최신 사용자 제약’** 절이다. 기존 사용자 제약을 공유본에 보완했으며 새 수치 결정은 없다.

## 6. 현재 포함하지 않는 범위

- MVP의 사용자 포지션 부분 종료.
- 첫 MVP에서 모든 언어·계정·개별 콘텐츠 데이터를 지원한다는 약속.
- AI 내러티브.
- 미래 활동 예상치를 새 지표 기준으로 도입하는 것.
- 미래 협찬권·실제 자산 설정/환매·사용권/사업 수익권·참가금 배분을 현재 제품의 계약 전제로 사용하는 것.
- 외부 마켓 인텔리전스/데이터 판매 사업의 구체화: 나머지 제품 구현 완료 후 재검토.

## 7. 구현 전에 남은 결정

### 제품의 의미에 관한 열린 질문

첫 사용자와 영어 키워드 MVP, 기록과 금전 참여의 구분은 채택됐다. 아래는 **사용자에게 어떤 가치를 약속하고 어떻게 표현할지 남은 질문**이다. 기술을 고르는 것만으로 답이 정해지지는 않는다.

| 질문 | 쉬운 예시 | 답에 따라 달라지는 것 | 현재 경계 |
|---|---|---|---|
| 가장 큰 사용자 가치는 무엇인가? | 선택하고 결과를 보는 재미, 내 감각에 대한 피드백, 먼저 발견한 이력 중 무엇 때문에 돌아올까? | 첫 화면의 약속·결과 화면·반복 이용을 관찰할 기준 | 가치들의 최우선 순위는 미정 |
| 칩을 거는 행동은 무엇을 표현하는가? | 논란으로 퍼질 것 같아 선택한 경우, 그 대상을 지지했다는 뜻일까? | 버튼 문구·입력·공유 기록의 해석 | 관심·호감·지지는 구분하지만 칩의 최종 표현 의미는 미정 |
| 어떤 선택을 잘했다고 인정하는가? | 먼저 발견했지만 돈은 늦게 넣은 사람과, 늦게 발견했지만 진입·종료를 잘한 사람 | 발견 이력·무료 점수·프로필·성과 설명 | 최초 판단과 금전 진입·손익은 구분. 점수·인정 기준은 미정 |
| 기록은 누구에게 어떤 가치가 있는가? | 친구에게 보여주는 이야기인가, 커뮤니티에서 반복된 판단을 확인하는 근거인가? | 공유 경험·열람자의 다음 행동·누적 기록 | 수신자와 최우선 사용 목적은 미정. 공식 평판·역량 인증을 약속하지 않음 |

정본의 K2·K3·K4·K7 질문을 현재 후속 결정과 대조해 정리했다. 과거의 첫 사용자·첫 대상 미정 표현을 다시 적용하지 않는다. 후보 답은 대화를 위한 선택지이며 새 요구사항이 아니다. 팀원은 가상 사용자 사례를 보고 자신이 가치 있게 느낀 순간과 다르게 해석한 표현을 설명하며 의견을 낼 수 있다.

제품 가치를 확인할 근거는 [제품 비전의 가설 표](PRODUCT_VISION.md#주요-가설과-확인할-근거)에 연결했다. 답변·인터뷰 반응과 실제 이용 행동, 기술 검증 결과는 각각 구분한다.
