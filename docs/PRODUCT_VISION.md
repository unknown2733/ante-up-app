# Ante Up — 제품 비전

기준일: 2026-10-11. 프로젝트 ID: `solana-colosseum`. 상태: 기존 사용자 선택을 정리한 공유용 초안.

처음 읽는 팀원은 [시작 안내](START_HERE.md)와 [출발점·사용자 사례](CONTEXT.md)를 먼저 보면 된다. 낯선 용어는 [용어집](GLOSSARY.md), 현재 채택 범위는 [결정사항](DECISIONS.md)으로 연결한다.

## 만들려는 제품

인터넷에서 남보다 먼저 읽은 관심의 흐름을 **당시 판단의 기록과 선택적 금융 참여**로 연결한다. 사용자는 키워드를 찾고, 판단을 남기거나 칩을 걸고, 외부 관심 변화를 관찰하다 원하는 순간 종료해 이후 결과를 확인하고 공유한다.

**Call it. Ante up. Prove it.**

작업 원라이너: “A market for early calls on internet attention. Search a keyword, record your call, and optionally take a position on its growth.” 실제 구현 범위에 맞춘 최종 제출 문구 확인은 남아 있다.

## 해결하려는 문제

다음에 뜰 아티스트나 퍼질 밈을 먼저 발견했을 때, ‘나는 먼저 알았다’는 판단을 당시에 남기고 나중의 관심 변화와 함께 제시하고 싶은 욕구에서 출발한다. 같은 관심 변화에 자본으로 참여하고 싶은 수요도 별도 경로로 다룬다.

이 문제·수요 설명은 현재 제품의 가설이다. 실제 고객 반응·유료 수요·반복 이용은 아직 검증되지 않았다.

## 첫 사용자와 참여 가치

첫 사용자는 **X·밈·트렌드를 남보다 먼저 찾는 온체인 참여자**다. 검색과 조기 판단 기록을 첫 행동으로 삼고, 금전 포지션은 선택 경로로 둔다.

| 참여 경로 | 제공하려는 가치 |
|---|---|
| Caller / 기본 사용자 | 무엇을 언제 판단했는지, 이후 관심이 어떻게 변했는지 보여주는 이력과 참여 경험 |
| Trader / Pro | 동일한 키워드의 관심 변화에 롱·숏 등 실제 구현된 거래 방식으로 참여 |
| LP | 키워드 시장에 자본을 공급하고 설계된 순손익에 참여; 손실과 지급 부담도 존재 |
| 키워드 등록자 | 아직 없는 대상의 참여 공간을 비용 기반으로 등록 |
| 기록 열람자 | 공유된 판단 시점·원래 대상·후속 관측을 대조하고 다음 참여를 판단 |

이들은 서로 다른 고정된 사람 분류가 아니라 같은 사용자가 선택할 수 있는 참여 경로다. 현재 방향만으로 크리에이터에게 자동 보상·지분·협찬 계약을 부여하지 않는다.

## 제품의 원칙

- 같은 키워드의 외부 관심 관측이 판단 기록과 금융 참여를 연결한다.
- 최초 판단 시점과 실제 금전 진입 시점, 기록 성과와 실제 손익을 구분한다.
- 원하는 순간 종료해 결과를 확정하는 경험을 지향한다. 고정 기한·사건·목표값을 먼저 고르는 것이 기본 경험은 아니다.
- 호감·지지·평판과 측정된 관심을 구분한다. 관심 증가가 판단 전체의 옳음이나 금전 이익을 자동 뜻하지 않는다.
- 당시 원문·지표·시점·종료 결과를 확인하는 기록을 지향한다. 구체적 검증 보장은 명세와 실제 근거에 따른다.
- 기본 모드와 Pro를 분리하되 같은 키워드 시장 아래 상호작용한다.

## 왜 Solana인가

사용자가 채택한 연결 방향은 세 가지다.

1. **ICM / Token Supercycle:** 인터넷에서 발견한 대상에 판단과 자본으로 참여하는 소비자 제품이라는 상위 방향.
2. **SAS:** 당시 선택·출처·종료 결과를 연결해 외부에서 확인하도록 설계하는 중심.
3. **모바일 우선·Seeker 실기기 데모:** 발견부터 참여·종료·공유까지 실제 모바일에서 사용하는 경험.

이는 채택된 제품 방향이다. SAS 스키마·발급자·보존·검증 범위, 실제 Solana 사용과 Seeker 지원 기능은 구현 명세·검증이 남아 있다. AI 내러티브는 현재 범위에서 제외한다.

## 장기 비전과 검증할 가설

**The financial layer for internet attention.**

하나의 측정 가능한 관심 시장과 완주 경험에서 출발해 반복 참여를 검증하고, 데이터와 거래 조건을 갖춘 대상의 범위를 넓힌다. 첫 MVP는 영어 키워드다. 다른 언어·계정·개별 콘텐츠는 확장 가능성으로 남긴다.

공유 기록 → 결과 확인 → 다음 판단의 반복, 등록비 기반 참여, 거래 관련 과금은 검증·설계가 필요하다. 재방문율·거래 전환율·수익 목표의 숫자는 현재 확정하지 않았다. 외부 정보/마켓 인텔리전스 사업의 구체화는 나머지 제품 구현 완료 이후로 유보했다.

### 주요 가설과 확인할 근거

**가설은 ‘그럴 것 같다’는 제품의 기대, 근거는 실제로 보고 확인한 내용**이다. 팀원이 아이디어에 공감했다는 반응과 사용자가 반복 이용했다는 관찰은 서로 다른 근거다. 아래 표는 기존 가설을 확인하기 위한 **검증 제안**이며, 검증 완료·실험 일정·성공 수치·새 기능을 확정한 것이 아니다.

| 확인할 가설 또는 성립 조건 | 도움이 되는 근거의 예시 | 가설이 약해지거나 재설계가 필요한 신호 |
|---|---|---|
| 무료 판단 기록 자체에도 가치가 있다 | 금전 참여 없이도 기록을 남기고, 이후 결과를 다시 확인하거나 공유하는 행동과 그 이유 | 실제 금전 보상이 있을 때만 쓰려 하거나 당시 기록을 다시 볼 이유를 찾지 못함 |
| 공유와 결과 확인이 다음 참여로 이어진다 | 기록을 받은 사람이 근거를 읽고, 결과를 보러 돌아오거나 새 대상에 판단을 남기는 흐름 | 링크를 열어도 내용을 이해하지 못하거나 결과 확인 뒤 다음 참여 이유가 없음 |
| 사용자가 관심 변화와 자신의 판단·손익을 구분한다 | 같은 가상 사례에서 관심 증가·호감·발견 시점·비용 포함 손익을 자신의 말로 구분하는 설명 | 논란으로 관심이 늘면 지지했다고 느끼거나, 관심 상승이 곧 이익이라고 계속 오해함 |
| 키워드 등록과 금전 참여에 지불할 이유가 있다 | 비용·권리가 구체화된 뒤 필요한 키워드를 실제 등록하거나 거래 조건을 확인하고 참여한 행동과 이유 | ‘무료면 좋겠다’는 반응만 있고 비용과 제공 가치가 명확해진 뒤 참여하지 않음 |
| 외부 LP에게 자본을 공급할 이유가 있다 | 손실·비용·평가·출금 조건을 이해한 뒤의 참여 반응, 이후 실제 조건에서의 예치·유지 행동 | 고정 이자·즉시 출금·원금 보장을 기대해야만 참여하려 함 |
| 데이터와 보호형 거래가 약속한 권리를 뒷받침한다 | 실제 데이터의 결측·지연·정정 확인, 명세가 정해진 뒤 롱·숏·동시 종료·반복 거래·LP 출금의 회계/계약 검증 | 관측 누락을 실제 0으로 처리하거나, 데이터만으로 지급액이 늘고 필요한 자산·권리가 확보되지 않음 |

마지막 행은 고객 수요와 별개인 **기술·경제 구조의 성립 조건**이다. 인터뷰 호응이나 단순 가격 시뮬레이션만으로 확인할 수 없다. 이 표의 가설이나 성립 조건이 검증 완료됐다는 근거는 공유본에서 확인되지 않았다. 과거 합성 계산은 가정이 제한된 설계 검토다.

첫 이용자를 대상으로 무엇을 먼저 확인할지는 팀 논의가 필요하다. 무료 기록의 가치, 공유받은 사람의 이해, 실제 비용을 제시한 뒤의 반응을 각각 따로 볼 수 있다. 이 설명은 검토 방법의 제안이며 새 계측·실험·개발 우선순위 승인이나 외부 실행 항목 등록이 아니다.

관련된 [열린 제품 질문](PRD.md#제품의-의미에-관한-열린-질문)과 [구현 전 결정 목록](PRD.md#7-구현-전에-남은-결정)을 함께 읽는다. 이후 근거가 생기면 확인 시점·대상·조건·결과를 남겨야 하며, 몇 사람의 반응을 전체 시장 수요로 확대하지 않는다.
