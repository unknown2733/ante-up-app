# Bounded reference and keyword collection on Devnet

The existing `solana` X Counts collector keeps its own state. Each added keyword gets a separate collection directory, candidate journal, lock, heartbeat name, and budget. The indexer must retain its existing candidate paths when another path is added; `deploy/compose.tariff-collector.yml` appends `tariff` through `ANTE_UP_INDEXER_EXTRA_CANDIDATES_JSON`.

For `tariff`, the approved test setting uses the finalized market address `CyYjBcb4LyuyLN1Akaf2eXXJV5GhFUkaPNb7caLCuHN6`, `expressions:["tariff"]`, query version `1`, and its registered seed. `scripts/collect-devnet.mjs` checks Devnet genesis, market PDA, query hash, query version, and publisher authority before any X request. It rejects an invalid or mismatched market instead of importing another keyword's history.

The operator-owned `/state/tariff/collection-config.json` sets `estimatedCostMicros:5000` for recent Counts and `initialEstimatedCostMicros:10000` for the 28-day archive. `initialLimitMicros:1000000`, `dailyLimitMicros:1500000`, and `totalLimitMicros:47000000` bound reservations in this market's durable state. These are conservative local estimates in micro-USD, not a verified X invoice or an account-wide cap. Failed and uncertain requests retain their reservation. Check X's current pricing and the account's spending limit before expanding this schedule.

Bootstrap is a separate one-shot `--execute --initial` invocation. Confirm its stored minute observations and finalized snapshot before starting the `--execute --follow` service. The service publishes a later completed five-minute batch, and its health check fails when the last poll becomes stale. A valid snapshot does not graduate the bonding curve or grant spot-pool, Pro, or LP rights.

The reference YouTube path reads only the three approved video IDs. `reference-youtube-schedule.ts` needs an operator-owned API-key file and `ANTE_UP_YOUTUBE_ALLOW_QUOTA=1`; it reserves at most one request per six hours, four per UTC day, and 120 per rolling 30 days. No key or host timer is present yet. X Post Lookup has its own separate bounded schedule. These reference observations update charts and source metadata only; they never become a keyword market's settlement feed.
