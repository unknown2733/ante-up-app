# 본딩커브 데이터 병렬 진행과 하루 평균 초기값

## 맥락

사용자는 외부 지수와 독립적인 본딩커브 거래 기간에 데이터 수집·계산을 병렬 진행할 수 있음을 확인했다. 이전 최소 활동량 제안을 시장 등록·커브 거래의 선행 조건으로 해석하지 않는다. H=3일/D=7일과 과거28일 선조회 방향은 유지한다.

## 결정

### 거래와 데이터 준비

> 등록 시 본딩커브 거래와 과거 데이터 조회·지속 수집·EWMA 계산을 병렬로 진행한다. 커브의 가격은 매수·매도와 커브 규칙으로 정하며, 외부 지표의 낮은 활동량·큰 변동이나 준비 미완료만으로 커브 거래 개시를 막지 않는다.

- 지표 계산이 가능하면 관측·성장률을 표시하고 준비 상태를 구분한다. 0 분모는 임의 값으로 대체하지 않는다.
- 본딩커브 매매손익과 외부 관심 지표 성과를 구분한다. 커브 기간의 외부 성장률을 금전 지급으로 약속하지 않는다.
- 등록 비용을 받는 기존 방향은 유지한다. 초기 조회와 상시 수집 비용을 어느 기간까지 포함하는지는 별도다.
- 자본·판매 조건 충족과 지표 준비 완료는 다른 상태다. 조건 충족 후 지표가 준비되지 않았을 때의 거래·이전 방식은 이번에 선택하지 않는다.

### EWMA 초기값

> 조회한 과거28일 중 가장 오래된24시간의 평균 활동률을 그24시간 끝의 초기값으로 삼고, 나머지27일의 관측을 시간순으로 재생한다.

- 첫24시간을 초기값에 사용한 뒤 재생에 중복 반영하지 않는다.
- 해당 하루 총960건이면 초기값은 분당960/1440건, 표시할 때 일960건 환산이다. 일별 합계와 분당 평균의 단위를 혼용하지 않는다.
- 첫 하루가 실제0건이면 초기값도0이다. 누락·조회 실패를0으로 취급하지 않는다.
- 이력이 추가되면 더 오래된 자료부터 같은 방식으로 초기화한다. 기존 결과·체결을 소급 변경하는 정책은 별도다.
- 초기값은 EWMA 상태이며 토큰의 최초 가격·본딩커브 가격·가격 표시 기준100이 아니다.

## 이유

- 커브에서 자본을 형성하는 동안 외부 지표도 준비할 수 있다.
- 초기 관심이 작거나 크게 변하는 키워드의 등록·커브 참여를 열어 둔다.
- 실제 하루 평균으로 시작해 한 분의 우연한 관측이나 임의0 초기화의 영향을 줄인다.

## 검토한 대안

- 지표 준비 이후에만 커브 거래 개시: 채택하지 않는다.
- 초기값을 임의0이나 최초1분으로 설정: 기본 초기화로 채택하지 않는다.
- 일100건·5활동일·초기값 민감도1%·다음 조회 확인: 이전 미채택 제안이다. 이번 승인에 포함하지 않고 등록·커브 개시 조건으로 적용하지 않는다.

## 영향

- 후속 사용자 선택으로 [커브 상단 대기 A안](<2026-10-11 지표 미준비 시 커브 상단 대기 채택.md>)을 채택했다. 아래 미선택 표기는 이 결정 당시 상태이며 대기 정책은 후속 결정을 따른다.
- 다음 결정: 자본 조건은 충족했지만 지표가 미준비인 시장의 대기 상태와 졸업/연동 시점.
- 커브 상단에서 신규 매수를 제한하고 매도를 허용하는 대기안, 전체 정지안, 현물 풀 우선 개방안을 비교한다. 모두 미채택이다.
- 졸업/연동 시점의 가격 연속성과 이전 성장의 소급 보상 금지, 기존 토큰 보유권을 유지한다.
- HOME, 핵심 결정 문서, 연결 설계에 반영한다. 유료 수집·계약 구현·배포는 이번 작업에서 실행하지 않았다.
- 재검토 조건: 선택한 커브의 판매 한도·이전 조건 또는 데이터 접근 제약 때문에 병렬 진행·안전한 대기가 성립하지 않을 때. 기한 미정.

## 근거

- 사용자 직접 선택, 2026-10-11 현재 대화.
- 직접 인용: “좋아. 그러면 본딩커브 거래랑 데이터 준비는 병렬로 진행하는 걸로 반영해줘. 초기값은 추천한 방식으로 픽스하고, 졸업 조건은 충족했는데 지표가 아직 준비되지 않은 경우를 어떻게 처리할지 선택지랑 예시로 정리해보자.”
- 직전 사용자의 설명: 본딩커브는 외부 수치와 독립적으로 거래하고 그동안 데이터가 축적되므로 초기 외부 변동성이 커도 커브 지급으로 연결되지 않는다는 취지.
- 영구 메시지 ID는 제공되지 않았다. 임계치와 대기 정책의 동시 승인으로 확대하지 않는다.
