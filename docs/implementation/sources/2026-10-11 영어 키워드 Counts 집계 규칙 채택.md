# 영어 키워드 Counts 집계 규칙 채택

## 맥락

[X Counts와 MVP 데이터 연동 우선](<2026-10-11 X Counts 채택과 MVP 데이터 연동 우선.md>)을 채택한 뒤 정확한 구문·표기 변형·관련 의미 확장, 일반 게시물·답글·인용·리포스트 포함 여부와 언어·조건 변경을 비교했다. 이번 결정은 영어 키워드 MVP의 측정 대상을 고정하며 특정 시장의 이름·별칭 목록이나 수집 주기를 정하는 결정은 아니다.

## 결정

> 등록된 정확한 구문과 제한된 표기 변형이 등장하는 영어 게시물의 발생량을 집계한다. 해당 표현을 직접 사용하는 일반 게시물·답글·인용을 포함하고, 단순 리포스트는 제외한다. 긍정·부정과 게시물 유형에 따른 가중치를 두지 않는다. 검색 조건은 등록 시 고정하며 변경은 별도 버전으로 관리한다.

| 요소 | 채택한 규칙 |
|---|---|
| 표현 | 정확한 단어·구문과 등록 시 명시한 제한된 표기 변형 |
| 표기 변형 | 같은 이름의 해시태그·붙여쓰기 등. 대소문자 차이는 별도 별칭으로 추가할 필요 없음 |
| 의미 확장 | 관련 주제·동의어·상위 카테고리를 자동 추가하지 않음. 별명·약칭은 표기 변형과 구분 |
| 일반 게시물 | 검색 조건에 맞으면 포함 |
| 답글 | 답글 자체가 검색 조건에 맞으면 포함. 부모 글의 주제만으로 포함하지 않음 |
| 인용 | 새로 작성한 내용이 검색 조건에 맞으면 포함. 인용 원문에만 키워드가 있는 글은 포함하지 않음 |
| 리포스트 | 단순 리포스트 제외 |
| 언어 | `lang:en`, 즉 X가 영어로 판정한 게시물. 특정 국가 제한을 뜻하지 않음 |
| 가중치 | 감정·게시물 유형에 따른 추가 가중치 없이 게시물 발생 건수 사용 |
| 변경 | 등록 시 조건 고정. 변경 시 버전을 분리하고 기존 시계열에 조용히 덮어쓰지 않음 |
| 별칭 합산 | 한 시장의 표현들을 하나의 OR 조건으로 조회. 별칭별 건수를 단순 합산해 같은 게시물을 중복 가산하지 않음 |

설명용 쿼리이며 첫 수집 대상 채택은 아니다:

```text
("Dubai chocolate" OR #DubaiChocolate) lang:en -is:retweet
```

## 이유

- 사용자가 선택한 구체적 대상의 의미를 유지한다.
- 긍정·부정·논쟁을 구분하지 않고 관심의 발생을 보는 제품 경험과 맞는다.
- 단순한 Counts 경로로 구현 가능한 범위에서 집계 의미를 설명한다.
- 조건 확장 때문에 활동 증가가 발생한 것처럼 보이는 문제를 줄인다.

## 검토한 대안

- 정확한 구문만: 표기 차이를 놓치므로 제한된 표기 변형까지 포함한다.
- 관련 의미를 폭넓게 묶기: 시장 의미와 운영자 해석이 섞이므로 자동 확장은 채택하지 않는다.
- 답글·인용 제외: 해당 표현을 직접 사용하는 대화·확산도 활동으로 포함한다.
- 단순 리포스트 포함: 현재 Counts 경로에서는 제외를 정책으로 명시한다. 전체 공유 확산은 별도 데이터 경로 검토 사항이다.
- 등록자의 자유로운 조건 변경: 시계열의 의미를 유지하기 위해 등록 시 고정한다.

## 영향

- 변경 문서: HOME, [핵심 결정과 비교 기준](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>), [연결 설계](<../20_Working/LP 자산과 외부 관심지수의 연결 설계.md>).
- 다음 선택: 첫 상시 수집 대상 수·구체 키워드, 집계 단위·조회 주기·비용 한도. 그다음 과거 이력·초기화·임시 EWMA와 결과 표시를 결정한다.
- 별칭 개수 상한·입력 검증 UI·동일 시장/중복 등록 판정·조건 변경 시 과거와의 연결 세부는 미정이다.
- 게시물 건수는 고유 작성자 수·조회수·전체 주제 확산량이 아니다. 편집 이력과 플랫폼 인덱스의 세부 처리는 실제 조회로 확인한다. Counts로 작성자별 상한이나 정교한 봇 제거를 구현했다고 해석하지 않는다.
- 데이터 지연 방어는 이전 결정대로 후속이다. 이번에는 기록만 수행하며 유료 API 호출·구현·시장 등록·배포는 실행하지 않는다.
- 재검토 조건: 실제 API 매칭이 의도한 집계와 다르거나 플랫폼 정책/검색 인덱스가 변경되는 경우. 별도 기한은 미정이다.
