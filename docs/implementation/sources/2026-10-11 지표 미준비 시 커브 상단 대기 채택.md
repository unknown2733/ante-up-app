# 지표 미준비 시 커브 상단 대기 채택

## 맥락

[본딩커브·데이터 병렬 진행](<2026-10-11 본딩커브 데이터 병렬 진행과 하루 평균 초기값.md>) 중 커브의 자본·판매 조건이 먼저 충족되고 지표는 아직 준비되지 않은 경우의 처리다. 지표 준비 완료 수치나 졸업 자본 임계치를 새로 정하는 결정은 아니다.

## 결정

> MVP는 A안으로 운영한다. 지표가 준비되지 않았으면 기존 본딩커브의 판매 한도 안에서 대기한다. 상단에서는 추가 매수를 제한하되 기존 커브 규칙에 따른 매도를 허용하고, 매도로 생긴 여유 물량만 다시 매수할 수 있게 한다. 실제 전환 시점에 자본·판매 상태와 데이터 준비를 함께 재확인한다.

- 대기 중 가격은 계속 커브의 매수·매도 규칙으로 결정한다. 외부 성장률을 환매 가격에 적용하지 않는다.
- 커브를 연장하거나 새 토큰을 발행하거나 풀용 예약 물량을 추가 판매하는 방식은 포함하지 않는다.
- 매도로 실제 준비금이 줄면 자본 조건이 다시 미달할 수 있다. 과거의 임계치 도달 사실만으로 졸업시키지 않는다.
- 조건을 다시 충족하면 기존 가격·토큰 권리 연속성 원칙에 따라 풀·지수 연동 단계로 전환한다. 기존 계약·지급 조건의 충족도 필요하다.
- 지표 준비를 기다리기 위한 전체 거래 정지(B)와 현물 풀을 먼저 개방하는 중간 단계(C)는 이번 MVP 기본안으로 채택하지 않는다.

## 예시

설명용 자본 조건이 50,000 USDC라면, 먼저 도달한 뒤 매도로 5,000이 나가 준비금이 45,000이 된 상태에서는 데이터가 준비돼도 자동 이전하지 않는다. 여유 물량 재매수로 자본 조건이 다시 충족되고 지표도 유효한 시점에 조건을 재검증한다. 이 금액은 확정된 파라미터가 아니다.

## 이유

매도 경로를 유지하면서 커브→중간 현물 풀→지수 연동이라는 추가 전환을 피한다. 상단의 신규 매수 제한은 이 선택의 수용한 제약이다.

## 영향과 후속 검토

- 후속 [2026-10-12 지표 준비 완료 기준](<2026-10-12 지표 준비 완료 기준 채택.md>)으로 기본 28일·결측 해결·양수 비교 분모·다음 조회 연결을 채택했다. 작은 양수의 거래 문턱은 후속이며 아래 미확정 목록은 이 결정 당시 상태다.
- 스택이 상단 대기·매도·여유분 재매수·조건부 이전을 지원하는지 검증해야 한다. 특정 스택의 지원을 확인했다는 결정은 아니다.
- 다음 데이터 결정은 지표 준비 완료 기준이다. 최소 활동량, 분모0·결측·이력 부족 처리와 초기값 민감도 기준은 아직 미확정이다.
- 상단 초과 주문의 거절 또는 부분 체결·환급, 이전의 원자성, 장기 대기의 수집 비용·종료 정책은 후속 명세다.
- 장기 대기 시 강제 종료·자동 환불·기한을 이번에 정하지 않는다.
- 재검토 조건: 채택 스택에서 매도 경로와 판매 상한을 함께 유지할 수 없거나 장기 대기 운영이 성립하지 않는 경우. 기한 미정.
- HOME와 두 기존 Working에 반영한다. 구현·유료 호출·배포는 수행하지 않는다.

## 근거

- 사용자 직접 선택: “A안으로 픽스하자”. 2026-10-11 현재 대화.
- 직전 응답의 A안은 커브 상단 매수 제한·매도 허용·여유분 재매수·현재 조건 재검증 방식이다.
- 영구 메시지 링크는 제공되지 않았다. 다른 대화의 A안이나 미채택 수치 기준으로 승인을 확대하지 않는다.
