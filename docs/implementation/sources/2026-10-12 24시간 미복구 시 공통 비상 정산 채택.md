# 24시간 미복구 시 공통 비상 정산 채택

## 맥락

[복구 후 재견적](<2026-10-12 데이터 장애 복구 후 재견적 채택.md>)을 적용하되 영구 미복구 때 계약을 종결할 경로를 정한다. 데이터 장애의 가격 유효성 위반 감지 규칙 자체는 후속이다.

## 결정

> 데이터 장애 발생 후 최대 24시간 복구를 기다리고, 그때까지 유효한 가격 계산 상태가 복구되지 않으면 장애 직전 마지막 검증 가격을 공통 기준으로 미결 포지션을 비상 정산한다.

- 시장별 장애 시작 시각은 사전에 정할 데이터 유효성 규칙 위반 시각에 연결한다. 일부 응답만으로 복구 기한을 반복 초기화하지 않는다.
- 장애 직전 마지막 검증 가격·관측 시각·버전을 보존하고 운영자가 사후에 정산 가격을 고르는 방식으로 사용하지 않는다.
- 기한 내 정상 복구는 기존 재견적·사용자 확인 경로를 따른다. 원래 만기가 이미 도래한 경우의 평가 시점은 다음 결정이다.
- 기한 내 미복구의 공통 비상 정산은 사용자별 자발적 종료와 다른 사전 계약상 예외다. 사용자가 유리할 때만 옛 가격으로 종료하는 선택권으로 제공하지 않는다.
- 정산에는 각 기존 계약의 보호·수량·비용·권리 규칙을 적용한다. 공통 기준가격은 모든 사용자에게 같은 금액을 지급한다는 뜻이 아니다.
- 24시간은 복구 대기 한도이며 모든 지급 트랜잭션이 그 순간 완료된다는 보장은 아니다. 정산 처리·검증·청구·종결성 세부 명세는 후속이다.

## 이유

복구 기회를 남기면서 무기한 대기를 피하고, 공통의 검증된 기준으로 종결 경로를 만든다. 장애 이후 미관측 손익은 반영하지 못한다는 한계를 수용한다.

## 영향과 후속 검토

- 후속 [데이터10분 노후화와 장애 기산](<2026-10-12 데이터 10분 노후화와 장애 기산 기준 채택.md>)으로5분 조회 실패 경고·10분 노후화 중단·계산 무효 즉시 중단과 조건 성립 시각부터24시간을 채택했다. 아래 감지/기산 미정 표기는 당시 상태다.
- 후속 [장애 비용 분리와 원만기 유지](<2026-10-12 장애 비용 분리와 원만기 유지 채택.md>)를 채택했다. 아래 비용·만기 미정 표기는 당시 상태이며 구체 요율·상품기간·선납 구조는 계속 후속이다.
- 다음 결정: 장애 중 유지비·프리미엄·보호 기간·만기. 이번 선택은 비용 면제·무제한 보호 연장·원금 환불을 뜻하지 않는다.
- 기존 만기가 24시간 대기 중 도래하는 경우와 비상 정산이 원래 만기보다 먼저인 경우를 구분해야 한다.
- 검증 가격 자체가 훼손된 경우, 비상 정산의 지급 재원·지급 부족 대응, 현물 토큰 전량 환매·LP 지분/잔여 자산·시장 재개는 별도다.
- 마지막 검증 가격 사용은 지급 능력의 입증이 아니며 실자금 개방 승인도 아니다.
- 재검토 조건: 실제 장애에서 24시간 대기·검증 가격·지급 계약이 의도한 운영을 제공하지 못할 때. 기한 미정.
- HOME와 기존 Working에 반영하며 구현·유료 호출·실거래는 수행하지 않는다.

## 근거

- 사용자 직접 지시: “좋아. 그러면 24시간 기다린 뒤 복구되지 않으면 마지막 검증 가격으로 공통 비상 정산하는 방식으로 일단 픽스하고 기록해줘. 다음으로 장애 중 유지비랑 프리미엄, 보호 기간과 만기는 어떻게 처리할지 선택지랑 예시로 정리해보자.”
- 2026-10-12 현재 대화. 영구 메시지 링크는 제공되지 않았다. 비용·기간 정책을 동시 승인한 것으로 확대하지 않는다.
