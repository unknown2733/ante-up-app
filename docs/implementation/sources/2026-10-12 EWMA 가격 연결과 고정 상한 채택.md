# EWMA 가격 연결과 고정 상한 채택

## 맥락

EWMA H3일/D7일, 졸업 가격 연속성, 주간 마감가 이월, 성장률+400% 상한, 최대 지급 예약을 하나의 규칙으로 연결한다. 과거 무가중 활동 산식/주간 원비율 연결은 이번 범위에서 변경하며 토큰 권리·기존 계약·주간 운영은 유지한다.

## 결정

### 가격과 상한

```text
r(t) = S(t) / S(t-7일)
g(t) = r(t) - 1
h(t) = min(r(t), 5)

유효한 정상 졸업: 0 < r_G < 5, P_G > 0
c = P_G / r_G
P(t) = c * h(t)
Pmax = 5 * c
```

- S는 반감기3일 EWMA 활동률이며 이미 정한 동일 이력·버전의 현재/비교값을 사용한다. 데이터 준비·활동률100·담보 조건을 별도로 충족해야 한다.
- +400%는 활동 성장률g에 적용한다. 졸업가격의5배 또는 매주 시작가격의5배로 바꾸지 않는다. 실제 성장률은 상한을 잘라 기록하지 않고 별도로 보존한다.
- c와 Pmax는 시장별로 고정하며 주간·진입·정정마다 다시 정하지 않는다. 졸업 순간 가격P_G가 이어지고 이미 발생한 성장을 전환 보너스로 지급하지 않는다.
- 졸업 시 r_G>=5이면 상한 미만으로 돌아올 때까지 지수 연동 전환을 기다린다. 기존 커브 상단 매수 제한·매도 및 여유분 재매수 규칙과 연결하고 실제 전환 시 모든 조건을 재검사한다. 원래부터 음수/0/무효 비교값은 개방하지 않는다.

### 주간 이월

- 주간 경계 당시 실제 게시된 마지막 유효 가격B_w와 같은 스냅샷의h_w를 함께 저장한다.
- 주간 표현은 P(t)=B_w*h(t)/h_w다. B_w/h_w=c이므로 고정 배율 식과 일치한다. 상한에 닿은B에 상한 전r/r_w를 곱해 배율을 바꾸지 않는다.
- 주간 가격 수익률P/B_w-1만 새 기준에서 시작한다. 활동 성장률g 자체·토큰 수량·매입 이력은 초기화하지 않는다.
- 경계에 유효 데이터가 없으면 거래/표시의 무효 상태를 명시하고 c를 임의 재설정하지 않는다. 부재한 경계값의 표시 세부는 구현에서 명세한다.

### 정정·정산·예외

- 주간 공개가격 기준, 원만기 정산가격, 현재 현물가격은 시각·버전별로 구분한다. 만기15분 검증으로 얻은 정산값을 사용해 이미 기록한B/h·c나 완료 거래를 소급 변경하지 않는다.
- 정정은 기존 정책대로 영향 이력을 재계산해 이후 유효 지표/가격에 반영한다. 상한 초과분을 다음 주 보상으로 이월하지 않는다.
- 상한 이상에서 가격은 평평하며 상한 아래로 내려와야 하락을 반영한다. 상한가격의 신규 롱은 양의 가격손익 여지가 없고 비용은 발생한다. 방향별 매력·시장 경제성이 균등해졌다는 결정은 아니다.
- 분모 무효·누락·계산 정밀도 문제에 임의 대체값/epsilon을 넣지 않고 기존 데이터 중단 규칙과 연결한다. 최소 단위·반올림·언더플로의 구체 구현은 후속 명세다.

## 예시와 확인

P_G10, r_G1.25이면c8/Pmax40. r가1.25/1.5/2/1/0.75/5/6/5.4/4.5일 때 가격은10/12/16/8/6/40/40/40/36이다. 주초r6/B40에서 다음r5.4는40을 유지한다. 원비율로40*5.4/6=36을 쓰는 방식은 채택하지 않는다.

C100·L5·P0=10 롱의 최대 총지급은1600, 숏600이다. 과거Pmax50 가정의롱2100을시장공통상수로사용하지않는다. 합성 비율100조합에서 고정계수식과 상한 적용 주간식이 일치함을 확인했으며, 실데이터 백테스트·경제 안전성 검증은 아니다.
