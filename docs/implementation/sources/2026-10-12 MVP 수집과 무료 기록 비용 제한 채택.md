# MVP 수집과 무료 기록 비용 제한 채택

## 결정

테스트넷 라이브 MVP의 비용 제한으로 직전 제안의 B 조합을 채택한다.

### 키워드 등록과 유료 수집

- 활성 유료 수집 시장은 최초 최대 5개다. 시장 등록·본딩커브 거래와 유료 데이터 활성화를 분리한다. 등록이나 졸업 임계치 도달만으로 유료 수집을 시작하지 않고 운영자가 명시적으로 활성화한다.
- 미지원 시장은 데이터 지원 대기로 표시하며 지표 준비 전 지수 연동 거래를 열지 않는다. 총 등록 시장 수를 5개로 제한한 결정은 아니다.
- 별칭·쿼리 변경만으로 유료 과거 조회를 자동 실행하지 않는다. 기존 포지션·기록의 이행에 필요한 시장을 단순히 슬롯 교체 목적으로 중단하지 않는다.

### API 요청과 예산

- 5개 시장·5분 조회·시장별 기본 1요청·1분 집계를 유지한다. 차트·가격 화면·리더보드·새로고침은 저장된 공통 관측을 사용한다.
- 초기 28일 조회는 승인한 시장/쿼리 버전 기준으로 수행하고 결과를 재사용한다. 정정 재조회·재시도·복구도 동일 예산에 포함한다.
- X 비용 상한은 UTC 일자당 $10, 기존 초기 X 예산 $100을 함께 적용한다. 초기 총예산 $150은 유지하며 월간 자동 반복 예산으로 해석하지 않는다.
- 현재 관측·필수 복구를 우선하고 정정 재조회, 새 시장 초기화·선택 작업 순서로 처리한다. 선택 작업 전에 당일 남은 정기 조회 비용을 확보한다.
- 정정 재조회까지 이 상한에 들어가는지는 실제로 측정한다. 예산 때문에 기존 정정 정책을 몰래 생략하지 않는다. 상한으로 필수 수집이 중단되면 기존 데이터 지연·장애 규칙을 적용한다.

### 무료 칩의 신규 진입과 미완료 의무

- 기존 동시 보유 한도 지갑당 3개·키워드당 1개를 유지한다.
- 추가 신규 진입 한도는 지갑당 이동 24시간 6건, 서비스 전체 이동 24시간 100건이다.
- 미완료 증명 의무는 최대 200건으로 제한한다. 열린 무료 기록과 종료 후 근거 보관/SAS 대기 기록을 모두 포함한다. 진입 시 자리를 차지하고 증명 완료 시 해제한다.
- 한도에 도달하면 신규 진입을 제한한다. 기존 기록 종료·보관·증명 발급은 계속 처리하며 별도 일일 발급 한도로 기존 의무를 미루지 않는다.
- 지갑별 한도는 다중 지갑을 막는 신원 증명이 아니다. 서비스 전체 한도는 비용을 제한하지만 일부 이용자의 슬롯 선점 문제를 해결하지 않는다.

### 보관·발급 비용

- 공통 시장 원자료는 배치별로 한 번 보관하고 개별 기록은 이를 참조한다. 같은 기록 ID/증명 버전의 재시도는 중복 업로드·발급되지 않도록 기존 처리 결과를 확인한다.
- 공유 카드 재조회·다운로드가 새 SAS나 원자료 업로드를 만들지 않는다. 정정 증명은 검증된 오류 처리에 따라 발급한다.
- 임시 저장소의 현재 사용량과 이미 수용한 작업의 예상 보관량 합계가 설정 용량의 80%에 도달하면 신규 무료 진입을 중단한다. 절대 용량은 샘플 크기 측정 후 정한다.
- 건수 한도만으로 바이트 비용을 보장하지 않는다. 잔여 업로드 예산·파일 크기도 확인하며, 미보관 원자료를 공간 확보 목적으로 자동 삭제하지 않는다.
- 기존 저장 장애·재시도·복구 정책을 유지하고 기존 종료와 미완료 의무 처리를 우선한다.

## 범위와 영향

이 수치는 초기 테스트넷 MVP의 비용 통제 설정이며 실측 후 재검토할 수 있다. 금전 칩·Pro의 경제적 권리나 거래 한도를 이번 무료 기록 한도로 변경하지 않는다. 한도 집행의 원자성·동시 요청 처리·온체인 진입 경로는 구현 명세에서 검증한다.

[라이브 유지 방향](<2026-10-12 라이브 MVP 유지와 비용 확장 제한.md>)을 구체화한다. 기존 지갑당 3개는 동시 보유 한도이고 이번 6건은 이동 24시간 신규 진입 한도이므로 함께 적용한다. 이전 결정을 전부 대체하지 않는다. 호스트·서비스 상품·월간 예산·저장 절대 용량은 미정이다. 실제 배포·결제·서비스 이전은 실행하지 않았다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천한 비용 제한 조합으로 일단 픽스하고 기록해줘. 다음으로 자체 호스팅할 수 있는 부분들이랑 외부 서비스를 유지해야 하는 부분들을 나눠서, 테스트넷 MVP 기준으로 선택지랑 추천안을 정리해보자.” 직전 추천 조합에 대한 승인이다. 영구 메시지 링크와 fragment ID는 제공되지 않았다.
