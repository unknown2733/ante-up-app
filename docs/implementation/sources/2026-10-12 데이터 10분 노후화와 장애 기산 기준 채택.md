# 데이터 10분 노후화와 장애 기산 기준 채택

## 맥락

기본 5분 조회·1분 관측 집계에 [복구 후 재견적](<2026-10-12 데이터 장애 복구 후 재견적 채택.md>) 및 [24시간 공통 비상 정산](<2026-10-12 24시간 미복구 시 공통 비상 정산 채택.md>)의 시작·복구 조건을 연결한다. 실제 X 지연을 측정해 최적화한 값은 아니다.

## 결정

### 유효 데이터 시각과 장애 판정

- 유효 데이터 시각은 필요한 구간이 빠짐없이 연결되고 검증된 마지막 관측 구간의 끝 시각이다. 마지막 요청 성공 시각·수신 시각과 구분한다.
- 데이터 나이는 현재 시각에서 유효 데이터 시각을 뺀 값이다. 중복 응답·연결 확인만으로 유효 데이터 시각을 갱신하지 않는다.
- 기본 5분 조회에서 한 번 실패하면 지연 경고와 복구 시도를 한다. 기존 검증 가격이 유효하고 데이터 나이가10분 미만이면 조회 실패만으로 즉시 가격 의존 거래를 중단하지 않는다. 기존 저활동·자본 제한은 유지한다.
- 데이터 나이가10분 이상이면 해당 시장의 신규 거래와 가격 의존 매도/종료 체결을 중단한다. 정확히10분부터 중단한다.
- 사용 중인 가격의 계산 근거가 무효로 확인되면10분을 기다리지 않고 즉시 중단한다. 새 응답만 잘못된 경우는 그 응답을 거부하고 이전 검증 상태의 유효성과 나이를 판단한다.
- 거래 체결 시마다 유효성·나이를 확인하며 작업자나 상태 표시 갱신이 늦었다고 오래된 가격을 허용하지 않는다.

### 누락과 24시간 기산

- 새 구간 중간이 누락되면 연속적으로 검증 가능한 지점까지만 유효 데이터 시각을 전진시킨다. 이후 자료는 보관하며 누락을 건너뛰어 지표를 확정하거나 누락을0으로 채우지 않는다. 확인된 실제0은 유효 관측이다.
- 노후화 장애 시작은 유효 데이터 시각+10분이다. 계산 근거 무효는 해당 무효 판정 시각이다. 이미 진행 중인 장애의 기산점을 뒤로 옮기지 않는다.
- 조건이 성립한 시각을 기준으로24시간을 계산한다. 수동 선언·늦은 감지·트랜잭션 실행 시각으로 늦추지 않는다.
- 장애 중 일부 응답·부분 복원만으로 기산점을 초기화하지 않는다. 해당 장애 시작 시각을 운영성 시간 요금 중단 시점에도 연결한다.

### 복구와 거래 재개

- 필요한 누락 구간·현재와7일 전 EWMA·산식 버전·유효한 분모/가격을 검증하고 데이터 나이가10분 미만이어야 한다. 장애 중 만기가 도래했다면 해당 만기 평가에 필요한 자료 복원도 확인한다.
- 유효한 가격 복구 후 기존 종료는 재견적·사용자 확인으로 처리한다. 신규 거래는 양쪽 활동률100 이상인 두 번의 새 정상 관측 및 자본 조건을 추가 확인한다.
- 데이터가 실제로 복구됐으나 활동률이100 미만이면 데이터 장애는 종료하고 저활동 종료 전용 상태를 유지한다. 신규 거래 대기와 데이터 장애24시간을 혼동하지 않는다.
- 같은 오래된 응답을 복구로 보지 않는다. 실제 검증 복구 후 다시 발생한 장애의 세부 사건 기록·동시성은 구현 명세로 남긴다.

## 예시

12:00까지 데이터를 검증한 후12:05 조회 실패는 경고다. 새 자료 없이12:10이 되면 중단하고 다음 날12:10을 비상 정산 기한으로 둔다. 프로그램이12:11에 기록해도 기산점은12:10이다. 새 응답에서12:02~12:03만 누락이면12:02까지만 연속 검증하며 다른 무효 사유가 없을 때 노후화 기산점은12:12다.

## 이유

정상5분 갱신 간격과 일시 실패를 허용하면서 실제 데이터의 노후화에 따라 거래와 복구 기한을 통제한다. 조회 성공 여부나 운영자 판단으로 시간을 연장하지 않는다.

## 영향과 후속 검토

- 10분 미만 데이터의 사용을 허용하는 대가로 오래된 가격 이용 위험이 남는다. 이번 결정은 앞서 유보한 체결 방어·오라클 안전성 검증을 대체하지 않는다.
- 다음 검토 후보: 관측 정정·확정 시점·버전과 이미 체결한 권리 처리, 데이터/오라클 게시 연결. 구체 요율·상품 만기·비용 부족·LP 지급/토큰 환매도 미정이다.
- 실제 관측 시각·게시 시각·온체인 시간의 연결, 잘못된 시각 입력 방어, 만기별 복구 상태와 동시성은 후속 구현에서 명세한다.
- 재검토 조건: 실제 집계 지연·조회 실패가10분 기준에서 과도한 중단이나 부적절한 가격 사용을 유발할 때. 기한 미정.
- 유료 호출·코드 구현·실거래·배포는 수행하지 않는다.
