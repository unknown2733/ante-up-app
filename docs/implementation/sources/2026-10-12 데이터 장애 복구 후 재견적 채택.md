# 데이터 장애 복구 후 재견적 채택

## 맥락

[정상 저활동의 종료 전용](<2026-10-12 저활동 종료 전용과 연속 회복 확인 채택.md>)과 달리 필수 데이터 누락·분모 0으로 가격을 검증할 수 없는 상황이다. 기본 조회 주기 사이의 정상 갱신 대기와 구분하며 장애 감지·노후화 시간 기준은 후속이다.

## 결정

> 해당 시장의 신규 거래와 가격 의존 체결을 일시 중단한다. 종료 의사는 보존하되 마지막 가격으로 지급하지 않고, 누락 구간과 지표 상태를 복구한 뒤 유효한 종료 견적을 제시하고 사용자가 다시 확인하여 전량 종료한다.

- 신규 유료 칩 매수·새 롱/숏·증액 및 가격 의존 매도/종료 체결을 중단한다. 마지막 유효 가격은 관측 시각과 함께 참고값으로 표시한다.
- 종료 의사 접수는 가격 확정·손익 종료·자동 체결 약속이 아니다. 복구 후 사용자 재확인을 받으며 과거/현재 가격 중 유리한 값을 고르는 권리를 부여하지 않는다.
- 누락을 0으로 채우거나 분모에 임의 값을 넣지 않는다. 마지막 검증 상태부터 관측 시각순으로 복원하고 현재·비교 EWMA와 버전을 검증한다.
- 복구되어 가격이 유효해지면 기존 종료의 재견적이 가능하다. 기존 종료에 활동률 100 회복이나 두 번 회복 관측을 요구하지 않는다.
- 신규 거래는 기존 원칙에 따라 두 활동률 모두100 이상인 두 번의 새로운 유효 관측과 자본·데이터 조건 확인 후 재개한다. 저활동이면 종료 전용을 유지한다.
- 이미 완료된 체결을 조용히 소급 변경하거나 기준가격·기존 권리를 초기화하지 않는다.
- 데이터 미확정 시 무료 기록의 실제 선택/종료 요청 시각을 보존하지만 지표 성과를 확정된 것처럼 만들지 않는다.
- 외부 지수와 독립적인 본딩커브 거래는 데이터 장애만으로 중단하지 않으며 연동 전환을 기다린다. 이미 졸업한 시장을 커브로 되돌리지 않는다.

## 이유

오래된 가격으로 종료할 수 있는 선택권에 따른 불균형을 줄인다. 대가로 데이터 장애 중 즉시 종료 체결을 보장하지 못한다.

## 영향과 후속 검토

- 후속 사용자 선택으로 [24시간 미복구 시 공통 비상 정산](<2026-10-12 24시간 미복구 시 공통 비상 정산 채택.md>)을 채택했다. 아래 대기·기준가격 미정 표기는 이 결정 당시 상태이며 비용·보호·만기는 계속 후속이다.
- 다음 결정: 최대 복구 대기 시간과 미복구 시 비상 정산 가격·기준 시각·강제 정산 여부·종결성. 이번 승인에 마지막 가격 최종 정산은 포함하지 않는다.
- 장애 중 비용·보호 기간·만기, 기존 토큰 환매와 LP 잔여 자산 처리, 지급 부족 및 실제 계약 구현은 후속이다.
- 복구 대기를 무기한 자금 잠금의 해결책으로 확정하지 않는다. 특정 대체 데이터 소스나 운영자 재량 평가도 채택하지 않는다.
- 재검토 조건: 실제 장애 복구·재견적·사용자 확인이 허용 가능한 경험을 제공하지 못할 때. 기한 미정.
- 코드·유료 호출·실거래·배포는 수행하지 않았다.

## 근거

- 사용자 직접 지시: “좋아. 그러면 복구 후 재견적 방식으로 일단 픽스하고 기록해줘. 다음으로 데이터 장애가 오래 지속될 때 얼마나 기다리고, 복구되지 않으면 기존 포지션을 어떻게 정산할지 선택지랑 예시로 정리해보자.”
- 2026-10-12 현재 대화의 직전 추천 방식. 영구 메시지 링크는 제공되지 않았다. 장기 장애 대안의 승인으로 확대하지 않는다.
