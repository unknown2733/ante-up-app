# 무료 공개 프로필과 진행 중 선택 공개 채택

## 결정

- 무료 공개 프로필에 평균 성과·종료 건수·진행 건수·무료 종료 이력과 진행 중 선택을 제공한다. 진행 중 선택은 대상 키워드·진입 시각·현재 참고 성과와 상태를 보여준다.
- 리더보드에서 프로필/집계 기록, 개별 기록과 증명 확인으로 연결한다. 기존 최근 7일/전체·유효 종료 성과 평균 집계는 유지한다. 진행 중 성과를 확정 순위에 합산하지 않는다.
- 개별 결과 카드와 검증 링크로 공유한다. 진행 중·종료·N/A·저활동·데이터 지연·증명 대기·오류/대체 상태를 구분한다. 성공 기록만 프로필 성과에 반영하지 않는다.
- Pro·LP의 앱 내 공개 프로필/소셜 노출과 전체 소셜 피드는 후속으로 미룬다. 이 결정은 Pro·LP 거래 기능 자체를 MVP에서 제거하지 않는다. 본인 거래/LP 관리 화면은 유지한다.
- 구현 명세 정리로 넘어간다. 코드 구현·배포 완료나 세부 기술 선택 전부의 승인을 의미하지 않는다.

## 범위와 영향

Fomo의 사람→이력→현재 선택 탐색 흐름을 무료 기록 중심으로 적용한다. 팔로우·실시간 소셜 알림·전체 활동 피드를 이번 공개 범위의 필수 기능으로 추가하지 않는다. 금전 칩의 공개 포트폴리오를 추가 승인한 것으로 해석하지 않는다. 앱에서 모아 보여주지 않는 Pro/LP도 온체인 조회 가능성과는 별개다.

이 결정은 [모바일 웹·운영자 관리·공개 faucet](<2026-10-12 모바일 웹 운영자 관리와 공개 faucet 채택.md>)에서 남겨 둔 공개 범위를 구체화한다. 기존 [리더보드 집계](<2026-10-12 무료 칩 평균 성과 리더보드 집계 채택.md>)와 기록/증명 정정 정책은 유지한다. 실제 화면·컨트랙트·API는 아직 구현/검증하지 않았다.

## 근거

사용자 직접 발언: “좋아. 그러면 무료 공개 프로필에 진행 중 선택까지 보여주는 걸로 픽스하고 기록해줘. Pro·LP 공개랑 전체 소셜 피드는 나중으로 미루고, 이제 구현 명세 정리로 넘어가자.” 영구 메시지 링크와 fragment ID는 제공되지 않았다.
