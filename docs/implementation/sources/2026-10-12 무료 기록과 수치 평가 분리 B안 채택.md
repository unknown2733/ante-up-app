# 무료 기록과 수치 평가 분리 B안 채택

## 결정

- 무료 칩은 등록된 시장의 지표 미준비·수집 미지원·데이터 장애에도 선택과 종료 기록을 허용한다. 졸업·LP·금전 거래 개방을 필요조건으로 두지 않는다.
- 성과는 유효한 양수 진입h와 유효 종료h가 있을 때 계산한다. 기준이 없으면 N/A와 사유를 남기며0%/성공으로 표시하지 않는다. 유효한 값이 있으면 임의로 N/A나 과거 유리한 관측을 선택하지 못한다.
- 유효한 저활동 지표는 숫자 성과와 `저활동 참고`를 함께 표시한다. 일 환산100건의 금전 개방 기준을 무료 성과 차단 기준으로 적용하지 않는다. 저활동 이력도 보존한다.
- 진입 기준이 없는 기록은 이후 관측으로 원 진입 시점의 기준을 자동 보충하지 않는다. 종료 후 새로 걸면 새 기록/새 기준으로 시작한다.
- 정상 진입 이후 장애가 생기면 현재 성과 갱신을 중단하고 마지막 유효 성과와 관측 시각을 참고로 보존한다. 장애 중 거두면 종료·슬롯 반환, 최종 성과N/A다. 후속 복구값으로 확정 결과를 자동 교체하지 않는다.
- 장애 중 거두지 않고 유지한 기록은 완전한 이력이 복구·검증되어 유효 관측이 게시되면 원 진입 기준으로 평가를 재개한다. 무료에는 금전 신규 거래의 두 번 연속 회복 대기를 추가하지 않는다. 기존5분 게시/10분 노후화 등 유효성 기준은 유지한다.
- 유효 종료h=0은 진입h>0이면−100%로 계산할 수 있다. 신규 진입h=0이나 비교 분모0은 성과 계산 불가로 구분한다. 누락을0으로 채우지 않는다.
- 무료에는 주간 강제 종료나24시간 후 자동 금전 비상 정산을 적용하지 않는다. Solana 거래 자체가 미확정이면 종료 요청 중/슬롯 반환 미확정이며 요청 시각으로 소급하지 않는다.

## 범위와 영향

무료 상승만·동시3개/시장당1개·대표h 성과·과거 기록 보존을 유지한다. 장애 때 손실 중인 기록을N/A로 종료할 여지는 남으며 마지막 유효 성과와 사유/이력을 보존한다. 향후 승률·순위·보상 도입 시 미평가 기록 처리와 선택 편향을 재검토한다. 미지원 기록은 데이터 지원 약속이 아니다.

SAS 발급 시점·발급자·상세 증거 패키지·보관 완료 기준·후속 정정 안내는 별도 결정이다. 금전 거래/Pro/LP의 기존 정책은 변경하지 않는다. 구현·배포는 미실행이다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천한 B안으로 일단 픽스하고 기록해줘. 다음으로 무료 칩의 진입·종료 기록이랑 SAS 증명을 언제 발급할지 선택지랑 예시로 정리해보자.”

직전 응답의 B안 및 추천 조건을 승인한 범위다. 영구 메시지 링크/fragment ID는 제공되지 않았다. [비교 이력과 다음 검토](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>)에 연결한다.
