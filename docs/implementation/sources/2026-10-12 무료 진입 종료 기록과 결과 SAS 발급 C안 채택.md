# 무료 진입 종료 기록과 결과 SAS 발급 C안 채택

## 결정

- 무료 칩은 진입·종료 모두 사용자 승인으로 Solana 프로그램에 기록하고, 종료 후 결과 SAS를 발급하는 C안을 채택한다. 진입 SAS는 별도로 발급하지 않는다. 진행 중 선택은 프로그램 기록과 진입 거래로 확인한다.
- 진입 시 기록ID·사용자·시장·방향·실행 시각/슬롯·사용 관측/버전·진입값 또는 N/A를 고정한다. 주간/졸업 경계나 후속 관측으로 진입 기준을 교체하지 않는다.
- 종료 거래에서 결과 또는 N/A와 종료 시점을 고정하고 슬롯을 반환한다. 종료는 한 번만 처리하며 새 선택에는 새 기록ID를 사용한다. 화면의 완료는 finalized 확인 후 표시한다.
- 종료 거래 확정 및 그 기록에 필요한 Arweave 근거 보관 확인 후 결과 SAS를 자동 발급한다. 추가 사용자 발급 신청은 요구하지 않는다. 실제 SAS 거래 확정 후 증명 완료로 표시한다.
- 종료/슬롯 반환과 외부 보관·SAS 발급 대기는 분리한다. 발급 실패는 기존 종료 결과를 되돌리지 않으며 같은 기록/버전/근거로 중복 없이 재시도한다. 저장 참조가 늦게 연결돼도 고정한 내용 해시와 결과는 바꾸지 않는다.
- 양수·음수·저활동·N/A 모두 결과 발급 대상이다. N/A는 선택/종료 사실과 평가 불가 사유를 증명하며 존재하지 않는 관측을 만들거나 숫자 복구까지 기다리지 않는다. 실제 존재하는 필수 근거는 보관 확인한다.
- 발급 시점의 새 지표로 결과를 재계산하지 않는다. 요청 시각·체인 실행 시각·관측 시각·발급 시각을 구분한다. 종료 거래가 실패하면 종료/슬롯 반환/SAS를 완료로 표시하지 않는다.

## 범위와 영향

예: 월요일h1.25 진입, 수요일12:03 종료 거래h1.5/+20%,12:05 근거 보관 확인,12:06 SAS 확정이라면 종료는12:03/+20%로 유지한다. 종료 확정 후 다음 칩을 사용할 수 있다. 시간은 가상 예시이며 서비스 지연 약속이 아니다.

발급자·키/스키마·증명 범위, 근거 패키지와 보관 완료 판정/재시도 한도, 정정·무효·공개·예산은 미정이다. 이 결정은 특정 SAS SDK 경로·저장 서비스 연동을 검증한 것이 아니며 실제 구현/업로드/배포는 미실행이다. 근거 대기가 증명 경험을 과도하게 지연하거나 운영 비용이 문제가 되면 재검토한다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천한 C안이랑 발급 순서로 일단 픽스하고 기록해줘. 다음으로 SAS를 누가 발급하고 정확히 무엇을 증명할지 선택지랑 예시로 정리해보자.”

현재 대화의 직전 추천 C안 및 발급 순서를 승인했다. 영구 메시지 링크/fragment ID는 제공되지 않았다. [비교 이력과 다음 검토](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>)에 연결한다.
