# 무료 칩 평균 성과 리더보드 집계 채택

## 결정

- 무료 칩의 지갑별 유효한 종료 성과 산술평균으로 순위를 매긴다. 개별 성과는 기존 `h_exit / h_entry - 1`을 사용한다. 금전 칩·Pro 손익과 합산하지 않는다.
- 최근 7일/전체를 제공한다. 최근 7일은 조회 시점에서 거슬러 올라간 기간이며 종료 시각으로 기록을 선택한다. 그 기간에 종료했다면 진입부터 종료까지 성과 전체를 집계한다. 시장의 주간 만기와 다른 화면 필터다.
- 공유 여부와 무관하게 해당 기간의 모든 유효 종료 기록을 집계하며 양수·0·음수를 포함한다. N/A는 평균에서 제외하고 별도 건수로 표시한다.
- 유효 종료 기록 1건부터 참여시키며 종료 건수와 진행 중 칩 수를 함께 표시한다. 동점은 공동 순위로 처리한다. 동일 점수 내 표시 순서는 구현 명세로 남긴다.
- 순위 행에서 집계 기록 목록, 개별 기록·증명 확인으로 연결한다.
- 종료 기록 확정과 계산 검증 후 순위에 반영한다. Arweave/SAS를 기다리는 경우 증명 대기, 발급·검증 완료 후 증명 완료로 구분한다.
- 원천 데이터 사후 정정은 기존 확정 성과를 유지한다. SAS 표기만 틀리면 검증된 원 기록 점수를 유지하며 증명 오류를 표시한다.
- 성과 계산 자체에 오류가 의심되면 해당 지갑 순위를 보류한다. 오류 기록만 제거해 손실이 빠지는 효과를 만들지 않는다. 정정 결과 검증 후 재집계하고 변경 이력을 표시한다.

## 범위와 영향

순위는 종료 기록의 평균 지표 변화이며 실제 투자·포트폴리오 수익률 또는 일반적 실력 인증이 아니다. 미종료 손실 선택, 소수 표본의 큰 성공, 여러 지갑 사용에 대한 완전한 보정은 하지 않는다. 표본 수·진행 건수·집계 기록 확인을 제공하고 순위에 경제적 보상을 연결하지 않는다.

기존 무료 칩 3개/키워드당 1개, 지표 계산, 종료 및 증명 오류 정책은 유지한다. 상세 전체 프로필/피드 공개 정책까지 승인한 것은 아니다. 실제 프런트엔드·집계 코드 구현은 미실행이다. 사용 편향이 데모의 의미를 훼손하면 집계 방식을 명시적으로 재검토한다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천한 리더보드 집계 방식으로 픽스하고 기록해줘. 다음으로 실제 저장 환경이랑 업로더, API·저장 비용을 어떻게 설정할지 테스트넷 MVP 기준으로 선택지랑 추천안을 정리해보자.” 직전 응답의 평균 성과 B안과 집계·상태 처리 조합을 승인했다. 영구 메시지 링크·fragment ID는 제공되지 않았다.
