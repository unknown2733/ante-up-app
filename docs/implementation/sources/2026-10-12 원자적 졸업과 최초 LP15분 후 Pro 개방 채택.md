# 원자적 졸업과 최초 LP15분 후 Pro 개방 채택

## 맥락과 결정

[커브 초기 설정](<2026-10-12 자체 커브와 초기 가격 물량 졸업 기준 채택.md>), [지원 대상](<2026-10-12 키워드 중복 처리와 첫5개 데이터 자본 공동 지원 채택.md>), [주간 운영](<2026-10-12 Pro 주간 공통 만기와 LP 처리 구간 채택.md>)을 연결한다. 테스트넷 MVP에 적용한다.

### 졸업 실행

- 마지막 커브 매수와 분리한 별도 졸업 거래로 실행한다. 자동 실행 프로세스가 호출하고, 다른 호출자도 사전 배정된 시장별 예산과 프로그램 검사를 우회할 수 없는 방식으로 요청할 수 있다. 운영자가 임의 전환가격을 선택하는 절차는 두지 않는다.
- 실행 당시 순판매1000·준비금1100·실제 시장 귀속 수수료, 데이터 준비·활동량, 유효0<r_G<5, 출연 한도와 실제 자금·담보 조건을 재검사한다. 먼저 매도가 체결돼 순판매량이 줄면 대기한다.
- 커브 종료, 준비금/시장 비용/필요 출연과 토큰 재고 이전, 같은 관측의 P_G=1.2와 r_G를 사용한 c/Pmax 고정, 환매 예약·버퍼 검사, 초기 잠금 LP 지분 생성, 현물/초기 LP 개방을 원자적으로 처리한다.
- 실패 시 전환의 상태/자산 이동을 모두 취소하고 커브를 유지한다. 기존 상단 초과 매수 제한·매도·여유분 재매수 규칙을 유지한다. 성공은 최초1회로 제한하며 재시도로 출연금/지분을 중복 생성하지 않는다.
- 같은 토큰과 기존 보유/매입 이력을 유지한다. 졸업 뒤 커브 주문은 거절하고 다른 가격의 현물 주문으로 자동 전환하지 않는다. Pro는 별도 개설이다.

### 최초 LP와 Pro

- 졸업 시 지수 연동 현물을 즉시 열고 초기 LP 구간을 시작한다. 초기 지분은 인출 잠금이며 외부 LP는 기존 N3 순자산 평가와 가용 한도로 참여한다.
- 최초 LP는 졸업 온체인 실행 시각부터 유효 NAV로 연속15분을 확보한다. 그동안 Pro를 개설하지 않는다. 현물 가격은 계속 갱신하며 매 실행 시 현재 NAV를 계산한다.
- 15분 후 LP 접수 구간을 닫고 주간 일정·데이터·활동량·주문별 담보 조건에 따라 Pro를 개방한다. 외부 LP가 실제 예치한 금액의 최소 목표는 추가하지 않는다.
- 외부 LP 예치가0이어도 자본이 감당하는 주문은 받는다. 초기 가용F0=3000의 자동 복원/출연은 없고 남은 실제 여력으로 주문을 제한한다.
- LP 구간 중 데이터 장애/유효 NAV 상실이면 처리 중단, 복구 후 연속15분을 다시 확보한다. 유효 가격이 있는 저활동은 기존 별도 규칙을 적용한다. 구간 종료 후 Pro 조건 미충족은 신규 개설 중단이며 LP 구간의 자동 무기한 연장을 뜻하지 않는다.

### 주간 경계

- 월요일08:30 KST 신규 Pro 마감·09:00 만기를 우선한다. 최초15분이 끝나도 마감 이후에는 끝나는 주기의 Pro를 개설하지 않는다.
- 최초 LP가 마감에 걸리면 다음 정기 LP 구간까지 연결한다. 겹치는 시간을 이중 가산하지 않고 최초 최소15분과 경계 이후 정기 최소15분을 모두 충족한다.
- 처음부터 열린/미확정 Pro가 없는 빈 주기는 만기 가격 검증15분을 생략한다. 주간 기준 연결과 현재 유효 NAV 확인, 정기 LP15분은 유지한다.
- 월요일08:20 졸업 예시: 현물/LP08:20 개방 →08:35에도 Pro 대기 →09:00 빈 주기 종료 →09:00~09:15 정기 LP → 조건을 충족하면09:15 이후 첫 Pro.
- 열린 Pro가 있으면 기존 만기 정산 확정 뒤 LP15분을 유지한다. 미청구 확정 정산금은 부채/예약으로 남기고 실제 수령을 모두 기다리지는 않는다. 장애 때 LP 재시작과 신규 개설 회복 조건을 유지한다.

## 영향과 후속

- [비교 문서](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>)의 별도 졸업·최초 LP15분 추천과 경계/장애 처리 세칙을 위 범위에서 채택했다. 다음은 무료 칩과 SAS 증명이다.
- 출연량·가격 상한·최대 지급·비용·주간 만기 등 기존 계약 조건을 변경하지 않는다. 졸업/예치가 수익이나 지급 안전성의 실증을 의미하지 않는다.
- 단일 거래의 계정/연산 한도, 원 단위 반올림, 지분 표시 단위, 실행 프로세스 가용성, 상태별 인수 테스트는 구현 명세에서 검증한다. 원자적 전환이나 기존 권리를 바꿔야 하면 재검토한다.
- 코드·체인 배포·API 실행·실제 자산 이전은 수행하지 않았다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천 조합으로 일단 픽스하고 기록해줘. 다음으로 무료 칩이랑 SAS 증명에 대해서 남은 결정사항들을 선택지랑 예시로 정리해보자.”

직전 추천의 별도 원자적 졸업·현물 즉시·최초 LP15분·외부 모집 최소액 없음·주간 경계 연결/빈 주기·장애 후 재시작을 승인했다. 영구 메시지 링크/fragment ID는 제공되지 않았다. 무료 칩/SAS의 새 추천은 이번 승인 범위가 아니다.
