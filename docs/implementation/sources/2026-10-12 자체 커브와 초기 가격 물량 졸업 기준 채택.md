# 자체 커브와 초기 가격 물량 졸업 기준 채택

## 맥락

[프로토콜 테스트 출연](<2026-10-12 테스트넷 졸업 자본의 프로토콜 출연 A안 채택.md>)을 전제로 본딩커브를 실행할 스택과 초기 경제 수치를 정한다. 우리 볼트 전환, 지표/자본 미준비 시 상단 대기와 매도, 같은 토큰의 권리 연속성을 지원해야 한다.

## 결정

### 스택과 자산

- 공개 시험 환경은 Solana Devnet이다. Rust/Anchor로 제한된 자체 커브 모듈과 볼트 전환을 구현한다. 기존 출시 프로토콜의 표준 졸업 경로를 그대로 사용하는 안은 선택하지 않았다.
- 표준 SPL Token, 프로그램 통제 PDA 계정, TypeScript 클라이언트를 사용한다. 구체 버전·배포 주소·코드 구조는 구현 명세에서 정한다.
- 결제 자산은 자체 테스트 토큰 tUSD다. 6자리 소수 단위를 사용하는 시험 자산이며 실제 달러/USDC에 대한 환매권은 없다. 네트워크 비용의 SOL은 별도다.
- 키워드 총발행량은 2000개, 커브 판매 상한은1000개, 나머지1000개는 졸업 후 볼트 판매 재고로 보관한다. 팀·등록자 무상 배분은 없다. 같은 mint와 기존 보유 수량을 유지한다.
- 키워드 토큰 고정량 발행 뒤 추가 발행 권한을 제거하는 방향을 적용한다. tUSD 발급 역할과 구분한다. 미판매 재고는 프로그램 통제 아래 두며 표시 가치를 결제 담보/NAV로 계산하지 않는다.

### 커브와 가격

```text
0 <= q <= 1000
p(q) = 1 + 0.2*q/1000
R(q) = q + 0.0001*q*q
매수 a개 대금 = R(q+a) - R(q)
매도 b개 총대금 = R(q) - R(q-b)
```

- q는 커브의 순판매량이며 누적 매수량·총거래량이 아니다. 비용은 별도 장부로 처리한다.
- 시작 한계가격1, 졸업 한계가격1.2, 판매목표1000개, 수수료 제외 졸업 순판매대금1100이다.
- 모든 키워드에 동일한 시험 가격 규칙을 적용한다. 기존 트래픽 규모로 최초 가격을 다르게 지정하지 않는다.
- 수식은 설명용 실수 표기다. 구현은 정수 최소 단위·반올림·오버플로 및 분할 거래 검증이 필요하다.

### 졸업

- 순판매1000개 도달과 실제 커브 순준비금을 함께 검사한다. 수수료·기부·출연금이 판매량 조건을 대신하지 않는다.
- 기존 데이터 준비·활동량·유효한 0<r_G<5·출연 예산·최대 지급 예약·버퍼 조건도 함께 충족해야 한다.
- 미준비 시 커브 상단 매수 제한·매도 허용·생긴 여유분 재매수를 유지한다. 매도로 순판매량이 내려가면 다시 목표를 충족해야 한다.
- 마지막 주문은 남은 판매량 이내 견적으로 제한한다. 실행 시 초과하면 전액 거절·재견적하며 다음 단계까지 섞어 자동 체결하지 않는다.
- 실제 전환 시 마지막 커브 가격을 이어받고 고정 배율/상한을 생성한다. 자산과 미판매 재고를 볼트로 연결하며 초기 지분은 기존 NAV 규칙을 따른다.
- 졸업 후 재고 매도는 기존 추가 예약·가용 검사로 제한한다. 토큰 재고 보유가 결제 자산의 충분함을 의미하지 않는다.

## 이유

커브·대기·볼트 전환을 좁은 범위에서 직접 표현하고, 초기 자본 참여의 가격상 보상을 유지하면서 시작·종료 한계가격 격차를20%로 제한한다. 숫자는 시험 규모 선택이며 실수요·시장가치의 추정치가 아니다.

## 검토한 대안

- Pump/Meteora/Raydium 표준 졸업 경로: 우리 볼트 직행·대기 규칙과의 차이 때문에 이번 기본안에서 제외.
- Doppler Solana 확장: 별도 훅/migrator·권한 검증이 필요한 후속 후보로 보존.
- 고정가1→1, 가파른1→2, 판매100/10000개: 초기 보상과 데모 규모의 비교 대안으로 보존.

## 영향

- 커브 수수료·등록비·출연 상한·버퍼·목표 가용 여력은 이번 승인에 포함하지 않는다. 과거 버퍼500/가용1500/출연5700 예시는 미확정이다.
- 50:50 물량 구분은 일반 AMM의 두 자산 가치 비율 조건이 아니다. 총공급·재고 정책을 바꾸면 기존 권리와 담보를 다시 검토한다.
- 봇의 물량 독점·샌드위치·반복 거래 수익 방어를 완료한 결정은 아니다. 전량을1100에 산 뒤 졸업 가격1.2로 환매하면 비용 전100 차익이 출연 자본에서 발생할 수 있음을 함께 유지한다.
- 코드·배포·실제 데이터 호출·자산 이전은 수행하지 않았다. 기존 스택 감사 결과가 새 코드에 자동 적용되지는 않는다.
- 재검토 조건: 초기 보상이 과도하거나 실제 구현의 정밀도·전환·예산 제약이 시험 목적과 충돌할 때.
