# 저활동 종료 전용과 연속 회복 확인 채택

## 맥락

[최초 개방 최소 활동률 100건](<2026-10-12 최초 지수 연동 최소 활동률 100건 채택.md>) 이후 운영 규칙이다. 관측과 가격 계산이 유효하나 현재 또는 7일 전 EWMA 활동률이 기준 아래로 내려간 상황에 적용한다. 데이터 결측·분모 0·지급 부족 대응은 별도다.

## 결정

> 개방 후 현재 또는 7일 전 EWMA가 일 100건 환산 미만이면 종료 전용 B안으로 전환한다. 신규 유료 칩 매수·새 롱/숏·증액을 중단하고 기존 토큰 매도와 포지션 전량 종료는 유효한 관측 및 기존 계약에 따라 처리한다. 두 활동률이 모두 100 이상으로 회복한 것을 두 번 연속 유효한 정기 관측에서 확인하고 자본·데이터 조건을 재검증한 뒤 신규 거래를 재개한다.

- 정상적인 지표·가격 갱신, 무료 기록·관찰·공유는 유지한다.
- 활동 감소만으로 기존 계약을 강제 종료하거나 가격을 고정·초기화하거나 본딩커브로 복귀하지 않는다.
- 부분 종료 미지원은 유지한다. 기존 보호·비용·만기는 원래 계약을 따른다. 새 기간의 갱신을 자동 허용하는 결정은 아니다.
- 회복 확인은 새로운 관측 구간이 정상 연결되는 정기 조회 두 번이다. 같은 값을 반복 조회한 것을 두 번으로 세지 않는다. 실제 지표값이 같아도 새 구간이 유효하면 관측은 구분된다.
- 어느 한 값이 다시 100 미만이거나 관측 유효성이 깨지면 연속 회복 확인을 충족한 것으로 보지 않는다.
- 정상 회복은 기준가격·EWMA·기존 권리를 초기화하는 이벤트가 아니다.

## 이유

작은 활동량 상태에서 신규 의무를 늘리는 것을 제한하면서 이미 참여한 사용자의 정상 종료 경로를 유지한다. 한 번의 경계값 회복만으로 재개하지 않는다.

## 영향과 후속 검토

- 후속 [데이터 장애 복구 후 재견적](<2026-10-12 데이터 장애 복구 후 재견적 채택.md>)을 채택했다. 아래 장애 미정 표기는 이 결정 당시 상태이며 장기 대기·비상 정산은 여전히 후속이다.
- 종료 전용은 기존 볼트 지급 위험을 없애지 않는다. 수익 포지션 종료·현물 매도에 필요한 자산과 남은 의무를 계속 확보해야 한다. LP 지분 출금은 별도다.
- 다음 결정: 결측·가격 노후화·분모 0에서 신규 거래와 종료 요청, 복구 가격·재개를 어떻게 처리할지. 이번 승인으로 오류 상태의 마지막 가격 정산이나 즉시 종료를 보장하지 않는다.
- 장애 중 비용·보호 기간·만기·장기 장애 종료 절차는 미정이다. API·계약 구현·실거래는 수행하지 않는다.
- 재검토 조건: 실제 저활동 상태에서 재개 반복·종료 처리·지급 조건이 의도한 경험을 제공하지 못할 때. 기한 미정.

## 근거

- 사용자 직접 지시: “좋아. 그러면 종료 전용 B안이랑 두 번 연속 관측으로 회복을 확인한 뒤 재개하는 방식으로 픽스하고 기록해줘. 다음으로 데이터가 누락되거나 분모가 0이 되는 경우에는 신규 거래랑 기존 포지션 종료를 어떻게 처리할지 정리해보자.”
- 2026-10-12 현재 대화. 영구 메시지 링크는 제공되지 않았다. 데이터 장애 정책의 승인으로 확대하지 않는다.
