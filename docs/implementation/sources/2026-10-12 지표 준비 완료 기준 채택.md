# 지표 준비 완료 기준 채택

## 맥락

본딩커브 거래와 데이터 준비는 병렬이며, 자본 조건을 먼저 충족하면 [커브 상단 대기 A안](<2026-10-11 지표 미준비 시 커브 상단 대기 채택.md>)을 적용한다. 이번에는 데이터로 지표를 계산할 준비가 됐는지를 결정한다. 작은 양수 분모의 금전 거래 개방 조건은 별도다.

## 결정

1. 고정한 집계 조건으로 기본 과거 28일의 관측 이력을 확보한다. 실제 0도 유효한 관측이며 28일 모두 양수 활동을 요구하지 않는다. 등록 후 새로 28일을 기다린다는 뜻이 아니다.
2. 확정한 가장 오래된 24시간 평균 초기값과 나머지 27일 재생을 사용한다. 반감기 3일·비교 간격 7일을 유지하고 필요하면 과거 이력을 보강한다.
3. 계산에 필요한 구간에 미해결 결측이 없고 현재와 7일 전 EWMA 상태를 재현할 수 있어야 한다. 조회 실패·미수신을 0으로 넣지 않는다.
4. 비교 분모가 0이면 성장률은 준비 중/N/A로 유지한다. 임의의 양수로 대체하거나 비교 간격을 줄이지 않는다. 이력이 부족하면 추가 조회 또는 지속 수집으로 보충하며 본딩커브는 계속 운영한다.
5. 초기화 후 다음 정기 조회에서 새 관측이 중복 없이 정상 연결되고 위 조건이 유지됨을 한 번 확인한다. 정상 연결은 데이터 최종성·조작 방지의 증명이 아니다.
6. 초기화 민감도 비교는 진단·이력 보강 수단으로 남긴다. 민감도 1%나 최소 활동량·활동일 수를 이번 완료 기준에 추가하지 않는다.

## 이유

현재 산식과 초기화 방식을 유지하면서 실제 0과 미관측을 구분한다. 계산 불가 상황을 인위적인 수익으로 만들지 않고, 커브 거래와 발견 기록은 계속 제공한다.

## 영향

- 후속 사용자 승인으로 [최초 연동 거래 B안·현재와 7일 전 각각 일 100건 환산](<2026-10-12 최초 지수 연동 최소 활동률 100건 채택.md>)을 채택했다. 데이터 준비와 구분하는 거래 개방 문턱이며 아래 미선택 표기는 이 결정 당시 상태다.
- 지표 준비 완료와 지수 연동 금전 거래 개방은 구분한다. 작은 양수 분모·현재 활동률의 거래 문턱, 자본·계약·지급 조건은 후속이다.
- 현재 활동 감소로 이미 체결된 권리나 과거 기록을 소급 변경하지 않는다. 운영 중 장애·분모 예외의 주문/종료 처리는 이번 최초 준비 결정에 포함하지 않는다.
- 다음 검토: 양수만 요구, 최소 활동률, 최소 활동률과 활동 분포를 결합하는 개방안. 모두 아직 제안이다.
- 재검토 조건: 실제 조회 가능 이력·결측·초기값 영향 때문에 채택 기준으로 유효한 지표 준비가 어려운 경우. 기한 미정.
- 유료 API 호출·제품 구현·배포는 수행하지 않는다.

## 근거

- 사용자 직접 지시: “좋아. 그러면 추천한 조합으로 일단 픽스하고 기록해줘. 다음으로 분모가 아주 작은 양수인 경우에 지수 연동 거래를 언제 열어줄지 선택지랑 예시로 정리해보자.”
- 2026-10-12 현재 대화의 직전 추천 조합(기본 28일, 실제 0/결측 구분, 양수 분모, 이력 부족 대기, 다음 정기 조회 연결 확인)을 채택한 범위다.
- 영구 메시지 링크는 제공되지 않았다. 이전 미채택 100건/일·5활동일·민감도 1%를 동시 승인한 것으로 해석하지 않는다.
