# 커브 비용 등록비 출연 한도와 버퍼 채택

## 맥락

[자체 커브·초기 가격·판매량·졸업](<2026-10-12 자체 커브와 초기 가격 물량 졸업 기준 채택.md>)과 [프로토콜 테스트 자본 출연](<2026-10-12 테스트넷 졸업 자본의 프로토콜 출연 A안 채택.md>)에 비용과 시장별 자본 한도를 연결한다. 모든 금액은 Devnet의 테스트 자산 tUSD 기준이며 실제 API 운영 예산과 구분한다.

## 결정

| 항목 | 채택 값 |
|---|---|
| 커브 매수·매도 수수료 | 각각 커브 적분 거래대금의0.1% |
| 커브 수수료 귀속 | 해당 시장80%·프로토콜20% |
| 등록비 | 성공한 등록1건당10 tUSD, 프로토콜 운영 계정100% |
| 시장별 최초 졸업 출연 상한 | 10000 tUSD |
| 고정 버퍼 B | 500 tUSD |
| 졸업 직후 목표 가용 여력 F0 | 3000 tUSD |

### 수수료와 등록비

- 매수는 적분 대금에 비용을 더하고, 매도는 적분 총대금에서 비용을 차감한다. 실패·대기 요청에는 거래 수수료를 부과하지 않는다. 체인 네트워크 비용은 별도다.
- 별도 커브 보유료·보호 프리미엄·졸업 수수료는 추가하지 않는다. 졸업 후 현물·Pro의 기존 비용 정책은 유지한다.
- 커브 판매 준비금 R(q), 시장 귀속 누적 비용 V, 프로토콜 귀속 수입/미지급을 분리한다. 매도 시 R은 비용 차감 전 총대금만큼 줄여 커브 수학과 일치시킨다.
- 시장 귀속80%는 졸업 전 해당 시장에 적립하고 졸업 시 초기 잠금 자본으로 넘긴다. 졸업 전 운영비로 인출하지 않는다. 등록자에게 별도 무상 물량·수익 청구권을 부여하지 않는다.
- 졸업 순판매대금 조건1100은 수수료 제외 값이다. 실제 남은 시장 귀속 비용은 출연 필요액을 줄이지만, 프로토콜 귀속액은 환매 담보/NAV에 포함하지 않는다.
- 등록 성공과 같은 온체인 거래에서10 tUSD를 수취한다. 등록 실패에는 등록비도 반영하지 않으며 동일 등록의 재시도에 중복 과금하지 않는다. 성공 후 단순 미졸업을 이유로 자동 환급하지 않는다.
- 등록비는 매수대금·LP 지분·졸업 출연 권리가 아니다. 테스트 등록비가 실제 X API 비용을 충당하거나 스팸 방어를 완성한다고 보지 않는다.

### 출연과 버퍼

- 출연은 최초 졸업 때 필요한 금액만 공급하되 시장별10000을 넘지 않는다. 실제 지표·의무·자산을 재검사하며 부족하면 졸업을 기다린다. 이후 손실에 대한 자동 재충전/보전은 없다.
- 기본 계산은 기존 최대 예약에 B500과 F0=3000을 더하고 실제 커브 잔여 자산·시장 비용 적립을 차감한다. 다른 의무가 있다면 함께 반영한다.
- F0는 초기 목표로서 현물 신규 매수와 Pro가 공유한다. 거래 후 매번3000을 복원하는 약속이나 Pro 전용 자본은 아니다.
- B는 신규 거래·LP 출금에서 제외하는 여유 자산이다. 최대 지급 예약을 대신하지 않고 확정 지급보다 우선하는 채무가 아니다. NAV에서 부채처럼 다시 차감하지 않는다.
- 버퍼 자동 해제나 기존 지급권 축소는 채택하지 않았다. 예외 사용 정책은 별도이며 기존 지급은 예약한 자산으로 처리한다.

## 이유

졸업 전후 사용자 비용 경험을 맞추고, 비용 적립·등록 과금·졸업 대기·다수 포지션·가용 부족을 시험할 수 있는 규모를 정한다. 최적 요율·통계적 안전 자본·메인넷 경제성의 검증값은 아니다.

## 예시

단조 매수로1000개 판매 시 수수료1.1 중 시장0.88·프로토콜0.22. r_G1.25에서 Pmax4.8, 현물 예약4800, 필요 출연7199.12, 볼트 자산8300, B500, 가용3000, 초기 NAV7100이다. 프로토콜분을 별도 분리한 가정이며 실제 비용 누적·원 단위 반올림에 따라 출연액은 달라진다.

## 영향과 후속

- [검토 문서](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>)의 비용·예산 제안은 위 범위에서 채택했다. 총 출연 예산50000의 보조 제안은 직전 사용자에게 제시한 추천 패키지에 포함되지 않았으므로 이번 승인으로 확정하지 않는다.
- 다음은 중복 키워드·데이터/출연 대상 배정·예산 및 수집 기간·졸업 전환/최초 LP/Pro 순서다. 원 단위 반올림·송금 실행 주기는 구현 명세에서 닫는다.
- 재검토 조건: 졸업 대기가 과도하거나 초기 가용 여력으로 의도한 데모를 수행하기 어렵고, 실제 회계 검증에서 시험값 변경이 필요할 때. 기존 계약에 소급 적용하지 않는다.
- 코드·배포·API 유료 실행·실제 자산 이전은 수행하지 않았다.

## 근거

사용자 직접 선택, 2026-10-12 현재 대화: “좋아. 그러면 추천 조합으로 일단 픽스하고 기록해줘. 다음으로 중복 키워드 처리랑 데이터·출연 지원 대상을 어떻게 정할지 선택지랑 예시로 정리해보자.”

직전 답변의0.1%·80:20·등록10·출연 상한10000·B500·F0=3000과 설명한 회계/환급 경계를 승인했다. 영구 메시지 링크/fragment ID는 미제공이다. 다음 시장 선정 방식과 구체 키워드는 미채택이다.
