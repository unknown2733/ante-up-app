# 키워드 중복 처리와 첫5개 데이터 자본 공동 지원 채택

## 결정

직전 [검토 문서](<../20_Working/관심 선택 제품의 핵심 결정과 비교 기준.md>)의 추천 패키지를 테스트넷 MVP에 채택한다.

### 시장 식별과 중복

- X·영어·정규화 대표 구문을 기준으로 한 시장만 허용한다. 대소문자와 앞뒤/연속 공백을 정규화하되 구두점을 무조건 지우거나 모든 단어를 붙이지 않는다.
- 제한된 같은 이름 표기·해시태그/붙여쓰기 별칭과 고정 집계 정책을 정렬·중복 제거한 명세도 비교한다. 대표 구문 또는 전체 집계 명세가 같으면 기존 시장으로 안내한다. 지갑·티커·이미지·별칭 순서·임의 버전 변경으로 우회하지 않는다.
- 다른 시장이 점유한 정확한 대표 구문/별칭을 다시 포함하면 충돌로 생성 거절한다. 부분문자열이나 게시물 겹침만으로는 거절하지 않는다. 의미상 유사어를 자동 통합하거나 기존 표현을 빼앗지 않는다.
- `Dubai Chocolate`과 ` dubai   chocolate `는 동일하다. 기존 허용 별칭에 명시된 `#DubaiChocolate`도 중복이다. `Trump`와 `Trump indictment`는 별도이며 `Elon Musk`와 `Musk`는 자동 병합하지 않는다.
- 등록 시 집계 의미·별칭을 고정한다. 임의 검색 연산자 입력·사후 시계열 교체는 허용하지 않는다. 수정/새 버전 절차는 후속이다.
- 중복 검사·식별자 점유·생성·등록비 수취를 원자적으로 실행한다. 동시 등록의 실패자에게 등록비10 tUSD를 받지 않으나 네트워크 비용까지 면제하지는 않는다.
- 등록자는 생성 이력을 갖는다. 외부 이름 소유권·데이터 수정권·수익권·운영 지원 우선권을 자동 부여하지 않는다.

### 데이터와 자본 지원

- 자유 등록과 즉시 커브 거래를 유지하면서 운영자가 첫5개 고정 실험 시장을 선정한다. 선착순·거래량·커브 진행률 경쟁으로 지원 대상을 정하지 않는다. 거래자 지갑 허가제를 도입하는 선택이 아니다.
- 명확한 영어 구문, Counts/필요 이력 확보 가능성, 성장·둔화·재유행 패턴의 다양성, 불필요한 데이터 중복 회피를 기준으로 삼는다. 아래 예시 이름은 실제 선정 목록이 아니다.
- 같은5개 시장에 데이터 지원과 출연 예산을 함께 배정한다. 총 테스트 출연 예산은50000 tUSD, 시장별 최초 출연 상한10000 tUSD다. 실제 API 운영비와 구분한다.
- 재무의 시장별 예산 예약은 볼트 자산이 아니다. 졸업 때 필요한 실제 금액만 이전하며 기존 커브·데이터·활동량·가격 비율·담보 조건을 모두 충족해야 한다.
- 예를 들어7199.12 출연 후 남는2800.88은 미사용 재무 예산이다. 자동 손실 보전·사용자 청구권·자동6번째 시장 지원으로 전환하지 않는다.
- 첫5개는 실험 중 고정한다. 낮은 인기나 Pro0개를 이유로 임의 수집 중단/자동 교체하지 않는다. 유통 토큰 환매와 LP 평가에도 데이터가 필요하다. 의도적 지원 종료를24시간 장애 비상 정산으로 대체하지 않는다.
- 지원 미선정/준비 중에도 커브는 거래할 수 있지만 지수 연동은 대기한다. 등록비가 데이터·출연·졸업·수익을 보장하지 않음을 표시한다.
- 무료 기록은 선택 시각을 남길 수 있으나 미수집 외부 성과를 만들지 않는다. 나중에 조회한 과거 데이터는 수집 시각과 출처를 구분하며 당시 직접 관측한 것처럼 소급 증명하지 않는다.

## 범위와 후속

총50000 예산은 이번에 채택했다. [직전 비용 결정](<2026-10-12 커브 비용 등록비 출연 한도와 버퍼 채택.md>)에서 미채택으로 남겨 둔 총액을 보완한다. 실제5개 구문·별칭, 실제 API 지출 상한/실행 기간, 지원 종료 절차, 정규화 구현 세부는 미정이다. 무기한 데이터 운영이나 실제 유료 호출 승인이 아니다.

다음 검토는 졸업 전환 실행 시점과 최초 LP·Pro 개방 순서다. 해당 추천을 이번 승인으로 확정하지 않는다. 코드·배포·자산 이전·API 실행은 수행하지 않았다.

## 근거

사용자 직접 발언: “좋아. 그러면 추천 조합으로 일단 픽스하고 기록해줘. 다음으로 졸업 전환 시점이랑 최초 LP·Pro 개방 순서를 어떻게 정할지 선택지랑 예시로 정리해보자.”

직전 추천 패키지의 표기/집계 중복 및 표현 충돌 차단·운영자 선정 첫5개 공동 지원·총50000 tUSD·상태 공개와 지원 유지 범위를 승인했다. 영구 메시지 링크/fragment ID는 미제공이다.
