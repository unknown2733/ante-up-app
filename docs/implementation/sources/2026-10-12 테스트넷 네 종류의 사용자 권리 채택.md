# 테스트넷 네 종류의 사용자 권리 채택

## 맥락

[테스트넷 볼트 담보 정산 B안](<2026-10-12 테스트넷 MVP 볼트 담보 정산 B안 채택.md>)에서 무료 칩·금전 칩·Pro·외부 LP의 권리를 구분한다. 아래 권리 방향을 채택하며 상세 지급식·보호 수치·출금 조건을 일괄 확정하지 않는다.

## 결정

| 종류 | 채택한 권리 | 종료·이전 |
|---|---|---|
| 무료 칩 | 본인의 선택 시점·관측·성과를 기록·공유·증명 | 거두면 결과 확정, 슬롯 재사용, 과거 기록 보존. 선택 이력 양도·현금/토큰/LP 수익 자동 청구 없음 |
| 금전 칩 | 실제 키워드 토큰 소유 | 커브와 졸업 후 같은 토큰 유지, 매도·전송 가능. 보유 자체에 만기/유지 프리미엄 없음. LP/프로토콜 수익권·보호·레버리지 자동 부여 없음 |
| Pro | 소유자별 비양도 계약의 보호·정산 권리 | 담보·롱숏·레버리지·기한·비용·보호 조건에 따라 전량 종료/만기 정산. 토큰·LP 지분 자동 소유 없음 |
| 외부 LP | 볼트 순자산 지분 | 수수료·프리미엄·거래 손익·비용을 반영한 순손익 참여, 조건에 따른 출금 요청. MVP 지분 양도 제외. 원금/고정수익 보장 없음 |

- 무료 칩 수량·점수식은 미정이며 지표 성과를 실제 금전 거래 수익과 구분한다.
- 금전 칩의 토큰 전송으로 원래 발견·매입 이력이 양도되지 않는다. 수신 토큰의 원가를 임의로 만들지 않는다. 무조건·무제한 지수가 환매까지 승인하지 않았으며 매도 견적과 지급 조건은 다음 결정이다.
- Pro의 거래 손실 한도와 비용을 진입 전에 공개하고 추가 개인 채무를 만들지 않는 방향을 채택한다. 원금 보장·무기한 보호·강제 종료 없음·특정 최대 지급액은 이번 승인에 포함하지 않는다.
- LP 수입은 우선 순자산에 누적해 지분 가치에 반영하고 출금시 실현한다. 동일 수입을 지분 가치와 별도 청구권에 중복 계상하지 않는다. 초기 잠금 지분의 개인적 회수 제한과 외부 LP 출금권을 구분한다.
- LP 평가액과 즉시 출금 가능액은 다를 수 있다. 손실 순위·예치 자산·회계식·출금 대기·초기 지분 수익 수령자·프로토콜 배분율은 미정이다. 이전 동순위 숫자 예시는 가정이다.
- 무료 성과를 금전 수익으로 소급 전환하지 않는다. 금전 칩/Pro/LP 전환은 명시적인 새 거래·예치이며 화면 모드 변경으로 자동 매도·담보화를 하지 않는다. 같은 지갑의 복수 역할은 허용하되 권리와 회계를 구분한다. 복수 동종 포지션의 세부는 후속이다.

## 이유

사용자가 무엇을 소유하고 무엇을 청구할 수 있는지 명확히 해 화면·계약·회계의 단위를 일치시킨다.

## 검토한 대안

- 무료 기록 양도/자동 보상권, 금전 칩의 별도1배 계약, 양도형 Pro, 고정 이율 LP는 현재 채택하지 않았다.

## 영향

- [모드 분리](<2026-10-10 기본 모드와 Pro 모드 분리.md>)의 기본 금전 칩 최종 권리 미정을 실제 토큰 매수로 구체화한다. 기존 모드 분리 전체를 대체하지 않는다.
- 다음 결정은 금전 칩 매도 조건과 Pro 롱숏 보호·지급식이다. 가격 상한 적용·최대 지급 담보·비용·만기·회복 가능성은 별도로 명세한다.
- 기존 지표·장애·정정B는 유지한다. 정정24시간·만기 검증15분은 여전히 미채택이다.
- 재검토 조건: 선택한 권리를 담보·회계·스택으로 일관되게 구현하기 어려운 경우. 메인넷 권리/실자금 지급 검증으로 확대하지 않는다.

## 근거

- 사용자 직접 선택, 2026-10-12 현재 대화: “좋아. 그러면 추천한 권리 구분으로 일단 픽스하고 기록해줘. 다음으로 금전 칩의 매도 조건이랑 Pro 롱·숏의 보호 범위와 지급액을 어떻게 계산할지 선택지랑 두쫀쿠 예시로 정리해보자.”
- 직전 추천: 개인 기록 / 키워드 토큰 소유 / 비양도 계약 정산 / 볼트 순자산 지분 및 명시적 모드 전환. 수량·요율·예시 손익·동순위 LP 가정을 최종 수치 승인으로 해석하지 않는다. 영구 메시지 링크·fragment ID는 미제공이다.
