# 테스트넷 비용 구조와 시험 요율 채택

## 맥락

[주간 공통 만기·LP 처리](<2026-10-12 Pro 주간 공통 만기와 LP 처리 구간 채택.md>), 최대 지급 담보·가격 비청산, 통합 예약, N3/L1 및 장애 비용 규칙에 비용 회계를 연결한다. 실제 LP 차입 방식의 복제가 아닌 테스트넷 볼트 담보·계약식 정산의 요금이다.

## 결정

### 계산 기준과 테스트 요율

| 항목 | 계산 및 요율 |
|---|---|
| 졸업 후 현물 | 매수·매도 거래대금 q*P의 0.1% |
| Pro 거래 수수료 | 개설 시 N=C*L의 0.1%, 별도 종료 수수료 없음 |
| 추가 볼트 자본 | K=max(M-C,0). M은 담보를 포함한 계약 최대 총지급액 |
| 자본 사용료 | K*0.02%*경과초/86400 |
| 보호 프리미엄 | N*0.05%*경과초/86400 |

- 현물 매수는 대금에 수수료를 더하고 매도는 대금에서 차감한다. 현물 보유 시간 요금은 추가하지 않는다. 본딩커브 수수료는 스택 선택과 연결해 후속 결정한다.
- Pro의 요율·계산 기준 금액은 개설 시 고정한다. 설정 변경은 새 계약부터 적용하고 기존 계약에 소급하지 않는다. 담보·예약과 미사용 비용을 별도 회계 처리한다.
- 성공한 체결 수수료는 조기 종료해도 환급하지 않는다. 실패·대기 요청에는 프로토콜 거래 수수료를 부과하지 않는다. 체인 네트워크 비용의 면제를 뜻하지 않는다.
- Pro 중도 전량 종료·정상 만기·비상 정산에는 별도 종료 수수료를 부과하지 않는다. 별도 운영성 시간 요금은 도입하지 않는다.

### 선납과 환급

- Pro 최초 납부액=C+개설 수수료+원만기까지의 시간 비용 전액. 부족하면 개설을 거절하고 계약 중 추가 충전을 요구하지 않는다.
- 경과시간은 개설부터 실제 계약 종료까지이며 원만기를 넘지 않는다. 조기·비상 종결 후의 미경과 시간 비용은 반환한다. 단순 종료 요청 제출만으로 발생을 멈추지 않는다.
- 장애 중 자본·보호가 존속하는 원계약 기간에는 기존 비용을 발생시키되, 원만기 이후 지급 대기에는 추가 시간 비용을 부과하지 않는다. 자동 만기 연장·갱신은 없다.
- 미경과 선납금은 환급 의무H/D로 유보하고 수익으로 미리 배분하지 않는다. 실제 발생한 부분만 귀속에 따라 수입으로 전환한다. 이미 잔고A에 포함된 금액을 수익 인식 때 다시 더하지 않는다.
- 추가 개인 채무는 없지만 담보 외 별도 비용 때문에 총손실은 담보액을 넘을 수 있다. 계약상 최대 납부 부담은 개설 때 선납하는 금액에 드러낸다.

### 배분

- 거래 수수료: 볼트 80%, 프로토콜 20%.
- 발생한 자본 사용료·보호 프리미엄: 볼트 100%.
- 볼트 귀속 수입은 순자산에 누적하며 초기 잠금 지분·외부 LP가 기존 L1 동순위 손익에 참여한다. 초기 지분 별도 현금 배당은 추가하지 않는다.
- 프로토콜 귀속액이 볼트에 남아 있어도 별도 외부 의무로 계상하고 가용/NAV에 중복 포함하지 않는다. 실제 송금·청구의 실행 주기와 최소 단위 반올림은 구현 명세에서 정한다.
- 수수료·프리미엄 수입으로 최대 지급 예약을 대체하지 않는다. 미경과 환급금은 새 거래의 지급 재원이 아니다.

## 두쫀쿠 예시

가격10, 고정 상한50, C100, L5, N500, 만기까지4일이라는 가정. 금액 단위는 테스트 USDC이며 가격·담보액·기간은 모든 시장에 적용하는 상수가 아니다.

| 항목 | 롱 | 숏 |
|---|---:|---:|
| M | 2100 | 600 |
| K | 2000 | 500 |
| 하루 자본 사용료 | 0.40 | 0.10 |
| 하루 보호 프리미엄 | 0.25 | 0.25 |
| 4일 시간 비용 선납 | 2.60 | 1.40 |
| 개설 수수료 | 0.50 | 0.50 |
| 최초 총납부 | 103.10 | 101.90 |

롱을 하루 뒤 가격12에서 종료하면 R200, 발생 비용1.15, 환급1.95, 사용자 순손익98.85. 프로토콜0.10·볼트1.05 귀속. 해당 포지션만의 볼트 순손익은100-200+1.05=-98.95다. 환급은 이익에 중복 가산하지 않는다. 4일 만기 가격12면 총비용3.10·사용자 순손익96.90이다.

## 검토한 대안과 한계

Pro 양방향 체결 수수료·성과보수·비용 잔고 차감·종료액 공제·고정 비환급 보호료·동적 위험 가격은 이번 MVP 미채택이다. 시간 비례 보호료는 옵션의 공정가치 모델이 아니며 짧은 보유·급변·반복 진입을 과소 과금할 수 있다. 시험 요율은 경제적 지속 가능성이나 시장 균형을 검증한 결과가 아니다.

## 영향과 후속

- 다음은 데이터 게시·관측 사용과 정정 마감·체결 및 만기/비상 정산 확정·버전 연결을 선택한다.
- 반올림·정산 청구/송금·최종 가격식과 상한 연결·스택은 구현 전 명세/검증이 필요하다.
- 반복 진입·롱숏 비용 차이·비용 수입 대비 볼트 손익의 시뮬레이션을 바탕으로 시험 요율을 재검토한다. 기존 계약 요율은 유지한다.
- 테스트넷 범위의 설계 결정이며 코드·배포·유료 데이터 실행이나 메인넷 경제성 승인이 아니다.
