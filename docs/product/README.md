# Ante Up product docs

These Markdown files are the source for the in-app Docs at `/docs`. The React renderer supports headings, paragraphs, ordered and unordered lists, inline code, bold text, and links. It treats HTML as text and permits only HTTPS links and local paths. Keep article links rooted at `/docs/<slug>` so the same files remain readable in the repository.

Explore combines observed Devnet markets with read-only **Preview** subjects. References use captured platform counts where available or official metadata and artwork. Metrics identify YouTube views, X post likes, or Spotify track streams with their source and UTC capture time. Third-party stream reports retain their attribution and report date; unknown report time zones remain unspecified. One observation is a snapshot, not a history or automatic feed. The Devnet `solana` market is the only previously verified collected market in this snapshot. Profiles, activity, and rankings use actual Devnet records.

The prose describes user-visible behavior and the current code boundary. Confirm claims against the integrated build before release, especially the final navigation, wallet flows, proof worker, and operational status.
