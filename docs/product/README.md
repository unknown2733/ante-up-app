# Ante Up product docs

These Markdown files are the source for the in-app Docs at `/docs`. The React renderer supports headings, paragraphs, ordered and unordered lists, inline code, bold text, and links. It treats HTML as text and permits only HTTPS links and local paths. Keep article links rooted at `/docs/<slug>` so the same files remain readable in the repository.

The R2 catalog can show a real subject with **Sample history**. Subject identity, metric provenance, and execution permission are separate. An image or recognizable title never establishes a live feed or a tradable pool. The Devnet `solana` market is the only previously verified collected market in this snapshot. No new market registrations or source subscriptions are implied by the Docs.

The prose describes user-visible behavior and the current code boundary. Confirm claims against the integrated build before release, especially the final navigation, wallet flows, proof worker, and operational status.
