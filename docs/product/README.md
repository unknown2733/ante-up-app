# Ante Up product docs

These Markdown files are the source for the in-app Docs at `/docs`. The React renderer supports headings, paragraphs, ordered and unordered lists, inline code, bold text, and links. It treats HTML as text and permits only HTTPS links and local paths. Keep article links rooted at `/docs/<slug>` so the same files remain readable in the repository.

Explore combines observed Devnet markets with read-only **Preview** subjects. References use captured platform counts where available or official metadata and artwork. Metrics identify YouTube views, X post likes, or Spotify track streams with their source and UTC capture time. Third-party stream reports retain their attribution and report date; unknown report time zones remain unspecified. One observation is a snapshot, not a history or automatic feed. The `solana` and `tariff` keyword markets have verified collected observations and graduated indexed markets; `wow` is still preparing data. Profiles, activity, and rankings use Devnet records.

The prose describes user-visible behavior and the code boundary. Confirm claims
against the deployed build before a release, especially wallet flows and proofs.
