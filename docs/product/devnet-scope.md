# Devnet scope

Ante Up is an experimental **Solana Devnet MVP** using test assets. Mainnet deployment, real asset safety, and a proven economic return are not claims of this release.

## What this preview includes

The public code includes a wallet connected chip flow, test-asset financial paths, X Counts processing, API and indexer, evidence modules, and example catalog data. Previously checked live collection covered the `solana` keyword. The broader R2 catalog adds real subjects for exploration; sample history does not turn into collected data or executable markets.

## What may be unavailable

Actions depend on market identity, source freshness, network, operator configuration, liquidity, and running services. Quotes and wallet requests can expire. Evidence and SAS issuance are asynchronous. The R2 public snapshot does not include every later proof, keeper, and operations follow-up. A chart or image is not proof a wallet action is available.

Earlier UI versions had real wallet checks on desktop and mobile. The unified R2 interface needs its own PC, Android Phantom, and Seeker regression after integration. Browser mocks and builds cannot substitute for those device checks.

## Read the labels

- **Observed Devnet data**: verify current source and chain status.
- **Sample history**: synthetic numbers for interface exploration.
- **Example activity**: fictional actors and actions, outside real rankings.
- **Finalized record**: a specific chain action, separate from proof issuance.
- **Financial quote**: an expiring test-asset proposal, not guaranteed execution or return.
